Cas pratique : le registre des emprunts

Le dernier projet, et le seul entièrement autonome : un tableau qui se remplit tout seul, un formulaire qui l'alimente, et des données venues d'ailleurs.

  • Exercice unique Le registre des emprunts 🎯 tableau dynamique · formulaire · statut calculé · bonus fetch

🟥 Aucun squelette. C'est le seul projet du parcours où aucun fichier JavaScript ne vous est fourni : vous créez le vôtre, et vous le branchez sur la page. C'est le geste que vous répéterez dans tous vos projets.

⚠️ Le bonus fetch demande un serveur local. Tout le reste du projet fonctionne au double-clic, comme d'habitude. L'énoncé explique comment lancer un serveur en une commande, si vous tentez le bonus.
