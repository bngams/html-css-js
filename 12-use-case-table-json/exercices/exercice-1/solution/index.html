Registre des emprunts

Livre Lecteur Jours restants Statut

Ceci est le corrigé en fonctionnement. Ouvrez la console (F12), puis ajoutez un emprunt.

Le statut se calcule à partir des jours restants : négatif → En retard (rouge), 7 jours ou moins → Bientôt dû (orange), au-delà → En cours (vert). Essayez -5, 3, puis 30.
