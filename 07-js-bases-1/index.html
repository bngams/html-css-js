Projet 7 · Jour 2 — après-midi

Décider et regrouper

Votre code savait s'exécuter. Il va maintenant apprendre à choisir — et à ranger ses instructions dans des blocs qu'on rappelle à volonté.

  • Exercice 1 Si… sinon 🎯 if · else · comparaisons · === contre ==
  • Exercice 2 Vos premières fonctions 🎯 function · paramètres · return
  • Exercice 3 Enchaîner les décisions 🎯 else if · et · ou · non
  • Exercice 4 Le jeu de devinette 🎯 un vrai mini-programme, tout réuni

📁 Le fichier change de nom. Depuis ce projet, votre code s'écrit dans app.js — la convention du fichier principal d'une application. C'est la troisième étape du fil « comment charge-t-on du JavaScript ? ».
