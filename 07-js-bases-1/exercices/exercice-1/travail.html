Votre fichier s'appelle maintenant app.js

C'est la seule nouveauté de forme du projet : la convention du fichier principal d'une application. Techniquement, rien ne change.

Cette page ne montrera rien. Tout le résultat de cet exercice s'affiche dans la console, comme à l'exercice 3 du projet 6.

Avant de commencer

  1. Ouvrez la console : F12 → onglet Console
  2. Gardez-la ouverte pendant tout l'exercice
  3. Ouvrez app.js dans VSCode
  4. Enregistrez avec Ctrl+S, puis rechargez avec F5

Une fois les dix étapes faites, la console doit afficher cinq lignes.
