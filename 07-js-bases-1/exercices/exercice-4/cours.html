1 · Un programme, pas une suite d'instructions

2 · Le squelette d'un jeu de devinette

const secret = Math.floor(Math.random() * 10) + 1;
const saisie = prompt("Devinez un nombre entre 1 et 10");
const proposition = Number(saisie);

if (proposition === secret) {
  alert("Gagné !");
} else {
  alert("Perdu. C'était " + secret);
}

Quatre lignes de préparation, une décision. Tout le reste de cet exercice consiste à rendre ce jeu plus juste et plus aimable.

3 · Le piège numéro un : comparer sans convertir

prompt() renvoie toujours du texte. Le nombre tiré, lui, est un vrai nombre. Les comparer directement avec === ne fonctionne jamais : 

const secret = 7;      // un NOMBRE
const saisie = "7";    // ce que rend prompt : du TEXTE

saisie === secret           → false    ⚠️ toujours faux
Number(saisie) === secret   → true     ✅

Un joueur qui tape la bonne réponse perdrait à tous les coups, sans la moindre erreur rouge. Convertissez une fois, au début, puis travaillez avec le nombre.

4 · Le piège numéro deux : « plus grand » sur du texte

Pour dire au joueur « c'est plus grand » ou « c'est plus petit », il faut comparer l'ordre. Là encore, le type décide : 

"10" > "9"          → false    ⚠️ comparaison alphabétique
Number("10") > 9    → true     ✅

Vous l'aviez vu à l'exercice 1 : deux textes se comparent caractère par caractère, comme dans un dictionnaire. Le "1" de "10" vient avant "9", et JavaScript s'arrête là. Encore une raison de convertir d'abord.

5 · Une saisie n'est pas toujours un nombre

Le joueur peut taper n'importe quoi, ou annuler. Voici ce que vous recevez réellement :

Le joueur…prompt() rendNumber(…) donne
tape 7"7"7
tape abc"abc"NaN
valide sans rien taper""0
clique sur Annulernull0

Deux surprises à connaître. Une saisie vide et une annulation donnent toutes deux 0 une fois converties — alors que le joueur n'a proposé aucun nombre. Et un texte non numérique donne NaN, pour Not a Number.

NaN a une propriété déroutante : il n'est égal à rien, pas même à lui-même. On le teste donc avec une fonction dédiée : 

isNaN(Number("abc"))    → true
isNaN(Number("7"))      → false

6 · Un seul essai — pour l'instant

Un vrai jeu redemanderait tant que le joueur n'a pas trouvé. Cela demande une boucle, que vous verrez au projet 8. Ici, votre jeu donnera un seul essai, puis la réponse.

Ce n'est pas une limite gênante : un jeu à un essai contient déjà toute la logique. La boucle ne fera que la répéter.
