Le jeu du nombre mystère

Ceci est le corrigé en fonctionnement. Ouvrez la console (F12) avant de recharger : le nombre secret y est affiché, ce qui vous permet de tester tous les cas.

Une boîte de dialogue s'ouvre au chargement. Rechargez pour rejouer avec un nouveau nombre.

Les cinq cas à essayer

Regardez d'abord le secret dans la console, puis répondez volontairement de chaque façon :

Vous répondez La boîte affiche
le bon nombre Gagné !
un nombre plus petit Trop petit.
un nombre plus grand Trop grand.
abc Ce n'est pas un nombre.
Annuler Trop petit. ← surprenant, et expliqué ci-dessous

Pourquoi l'annulation répond « Trop petit. » En annulant, prompt() ne rend pas un texte mais null. Et Number(null) vaut 0 — un nombre parfaitement valide, plus petit que le secret.

Le jeu ne peut donc pas distinguer « le joueur a proposé 0 » de « le joueur a renoncé ». C'est un défaut connu de cette version : le corriger proprement demande un test supplémentaire, que vous saurez écrire après le projet 8.

Dans la console

Trois lignes vous sont destinées, à vous le développeur :

  1. [triche] le secret est : …
  2. saisie : "7" → proposition : 7
  3. Proposition : 7 · Secret : 7 · Verdict : Gagné !

La deuxième est la plus instructive : elle montre côte à côte ce que le joueur a tapé et ce que le programme en a fait.
