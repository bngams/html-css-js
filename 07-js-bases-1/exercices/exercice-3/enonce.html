🎯 Objectif — Enchaîner plusieurs cas avec else if, combiner des conditions avec et / ou / non, et découvrir le piège de l'intervalle.

Prérequis : l'exercice 1 (if / else, les comparaisons) et l'exercice 2 (écrire une fonction avec return).

Un seul fichier : exercices/exercice-3/app.js

Il contient déjà deux valeurs fournies — habitantCommune et estEtudiant — dont vous vous servirez à partir de l'étape 7.

✅ Le travail — 10 étapes

Partie 1 — quatre tarifs avec else if

  1. Écrire une fonction categorie(age) qui renvoie "enfant" avant 12 ans, "jeune" avant 18, "adulte" avant 65, et "senior" sinon — une seule chaîne if / else if / else
  2. Afficher en quatre instructions : 8 ans : puis categorie(8), 15 ans : puis categorie(15), 30 ans : puis categorie(30), 70 ans : puis categorie(70)

L'ordre des cas n'est pas libre. Allez du plus restrictif au plus large. Si vous mettez age < 18 avant age < 12, le cas « enfant » devient inatteignable — et rien ne vous le signalera.

Partie 2 — le piège de l'intervalle

  1. Créer une boîte age contenant 70
  2. Ranger dans testMaths l'écriture mathématique naïve : 18 <= age < 65 — c'est volontairement faux, ne corrigez pas
  3. Ranger dans testCorrect le même test écrit correctement : la variable répétée de chaque côté, reliée par et
  4. Afficher en deux instructions : 18 <= age < 65 (maths) : puis testMaths, puis age >= 18 && age < 65 (JS) : puis testCorrect

Le visiteur a 70 ans : il n'est PAS dans l'intervalle 18–65. La bonne réponse est donc false.

L'écriture mathématique répondra pourtant true, sans la moindre erreur rouge. C'est le défaut le plus dangereux de ce projet : un test qui ment en silence.

Partie 3 — combiner plusieurs conditions

  1. Ranger dans gratuit le test : age inférieur à 12 ou ( habitantCommune et estEtudiant ) — avec des parenthèses autour du « et »
  2. Afficher le texte Gratuit : puis gratuit
  3. Afficher le texte Doit payer : puis l'inverse de gratuit, avec l'opérateur « non »
  4. Afficher, en une seule instruction : Visiteur de, puis age, puis ans, catégorie :, puis categorie(age)

🔍 Comment vérifier

Une fois les dix étapes faites, la console doit afficher exactement neuf lignes : 

8 ans : enfant
15 ans : jeune
30 ans : adulte
70 ans : senior
18 <= age < 65 (maths) : true
age >= 18 && age < 65 (JS) : false
Gratuit : false
Doit payer : true
Visiteur de 70 ans, catégorie : senior
Ce que vous vérifiez Ce que vous devez constater
Les quatre catégories enfant, jeune, adulte, senior — dans cet ordre, une seule par ligne
Le piège de l'intervalle La ligne 5 affiche true et la ligne 6 false, pour la même question
Le « non » Doit payer affiche exactement l'inverse de Gratuit
La réutilisation La dernière ligne rappelle categorie(age) : la fonction écrite à l'étape 1 ressert telle quelle
Aucun oubli Ctrl+F sur « TODO » dans app.js : aucun résultat

🧪 Manip — pourquoi l'écriture mathématique ment

Sur la page de travail, ouvrez la console (F12) et tapez ces trois lignes, une par une :

  1. 18 <= 70 → true
  2. true < 65 → true
  3. 18 <= 70 < 65 → true

JavaScript ne lit pas l'intervalle comme un tout : il enchaîne deux comparaisons. 18 <= 70 donne true, puis il compare true à 65 — et true vaut 1 dans un calcul. La question posée a disparu en route.

🏁 Comment savoir que j'ai fini

  • Les neuf lignes s'affichent, sans erreur rouge
  • Vous savez expliquer pourquoi 18 <= age < 65 répond true pour un visiteur de 70 ans
  • Vous savez que l'ordre des else if va du plus restrictif au plus large
  • Aucun TODO ne subsiste dans app.js

⏱️ Durée indicative

40 à 50 minutes. Les étapes 4 à 6 sont le cœur de l'exercice : prenez le temps de comprendre pourquoi les deux lignes se contredisent.
