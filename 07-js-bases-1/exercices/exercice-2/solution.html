Les quatre choses à retenir

1 · Sans return, le travail est perdu

multiplierSansRendre fait bien la multiplication. Le résultat est calculé… puis jeté, parce que personne ne le reçoit : 

function multiplierSansRendre(a, b) {
  a * b;          ← calculé, puis abandonné
}
→ undefined

Et aucune erreur rouge n'apparaît. C'est ce qui rend ce défaut si fréquent : le programme continue, avec une valeur vide qui se propage. Quand une fonction vous renvoie undefined sans raison apparente, cherchez d'abord le return manquant.

2 · Afficher n'est pas renvoyer

console.log(a + b)return a + b
Destinataire l'écran le programme qui appelle
Réutilisable ? non oui
Multiplié par 10 NaN le résultat ×10

C'est exactement pourquoi l'étape 9 fonctionne : prixTTC(24) * 2 n'est possible que parce que la fonction renvoie une valeur.

La règle : une fonction calcule et renvoie ; c'est celui qui l'appelle qui décide d'afficher. Mélanger les deux rend le code inutilisable ailleurs.

3 · Paramètre et argument

Deux mots pour deux choses différentes — la confusion est fréquente :

function prixTTC(prixHT) {     ← prixHT est le PARAMÈTRE
  return prixHT * 1.2;
}

prixTTC(24);                   ← 24 est l'ARGUMENT

Le paramètre est un emplacement nommé, écrit une fois. Les arguments sont les valeurs réelles, différentes à chaque appel. C'est ce qui permet d'écrire le calcul une seule fois et de l'utiliser trois fois, comme à l'étape 8.

4 · Les décimales à rallonge, et leur irrégularité

CalculRésultat
24 * 1.228.799999999999997
2 * 1.22.4 — exact
15 * 1.218 — exact

Vous aviez vu ce phénomène au projet 6. Ce que cet exercice ajoute, c'est qu'il est imprévisible : il ne touche que certains nombres. Impossible de deviner lesquels — d'où la règle : .toFixed(2) pour afficher, jamais pour calculer.

Les erreurs fréquentes

SymptômeCause
La console affiche undefined pour vos propres fonctions Le return manque — ou vous avez écrit console.log à sa place
ReferenceError: soustraction is not defined La fonction n'a pas été écrite, ou son nom est mal orthographié à l'appel (majuscules comprises)
La dernière ligne affiche NaN prixTTC affiche au lieu de renvoyer : il n'y a rien à multiplier par 2
Rien ne s'affiche, une erreur rouge en haut Une accolade manquante. Maj+Alt+F reformate le fichier et rend le décalage visible
La console affiche le code d'une fonction au lieu d'un nombre Les parenthèses manquent à l'appel : addition au lieu de addition(5, 3)
