Le squelette d'une page HTML

  • 📖 Cours
  • 📋 Énoncé
  • ✍️ À vous de jouer
  • ✅ Solution

🎯 Objectif — Écrire de A à Z le squelette minimal d'une page web valide, et vérifier qu'elle s'affiche correctement dans le navigateur.

Niveau : débutant absolu. Aucun prérequis : si vous savez enregistrer un fichier et ouvrir un navigateur, vous avez tout ce qu'il faut. Aucune installation, aucune ligne de commande. Vous écrivez du texte dans un fichier, vous rechargez la page, vous regardez le résultat.

📄 Le fichier à modifier

Un seul fichier : exercices/exercice-1/travail.html

Il existe déjà — vous n'avez rien à créer. Il contient les consignes sous forme de commentaires HTML, ces lignes encadrées par <!-- et --> que le navigateur n'affiche pas (voir la notion « Les commentaires » dans le cours).

🚀 Première fois : ouvrir le fichier

Vous allez travailler avec deux fenêtres côte à côte : VSCode pour écrire, le navigateur pour voir le résultat. Voici comment les mettre en place — une seule fois, au début.

  1. Dans VSCode, ouvrez le dossier de la formation : menu Fichier → Ouvrir le dossier… → choisissez le dossier 01-html-structure qui vous a été remis. L'arborescence apparaît à gauche.
  2. Dépliez exercices → exercice-1 et cliquez sur travail.html. Le fichier s'ouvre dans l'éditeur : vous y voyez les commentaires de consigne.
  3. Pour l'ouvrir dans le navigateur, au choix :
    • clic droit sur travail.html dans l'arborescence → Révéler dans le Finder (Windows : Afficher dans l'explorateur), puis double-cliquez le fichier ;
    • ou, si l'extension Live Preview est installée : clic droit → Show Preview.
  4. Placez les deux fenêtres côte à côte — VSCode à gauche, le navigateur à droite. Vous ne les quitterez plus de l'exercice.

La page est blanche ? C'est normal et c'est prévu. Le fichier ne contient que des commentaires, et le navigateur ne les affiche pas. Votre page se remplira au fur et à mesure que vous écrirez du contenu.

🔁 La boucle de travail, à répéter à chaque TODO :

  1. j'écris dans VSCode
  2. j'enregistre — Ctrl+S (Windows) / Cmd+S (Mac)
  3. je passe au navigateur et je recharge — Ctrl+R / Cmd+R (ou F5)
  4. je regarde ce qui a changé

Si rien ne change à l'écran, c'est presque toujours l'enregistrement qui manque. C'est l'erreur numéro un des débuts.

✅ Critères de réussite

Votre page doit contenir :

  1. Une déclaration de type de document (doctype) en première ligne de code — aucune balise avant lui. (Pensez à supprimer les commentaires de consigne au fur et à mesure : à la fin, le doctype doit être la première ligne du fichier.)
  2. Une balise <html> avec la langue déclarée en français
  3. Une section <head> contenant :
    • l'encodage des caractères en UTF-8
    • un <title> — mettez-y un texte différent du titre de la page, par exemple votre prénom ou « Mon premier site »
  4. Une section <body> contenant :
    • un titre de niveau 1 avec le texte « Ma première page »
    • un paragraphe qui se présente en une phrase, avec au moins un accent

Pourquoi deux textes différents ? Parce que <title> et <h1> ne s'affichent pas au même endroit, et c'est le point subtil de cet exercice :

  • <title> s'affiche dans l'onglet du navigateur (et dans les favoris, et dans les résultats Google) — jamais dans la page elle-même
  • <h1> s'affiche dans la page, en gros, tout en haut du contenu

En leur donnant le même texte, on ne verrait pas la différence. En les distinguant, vous la constatez d'un coup d'œil.

🔍 Comment vérifier

Ouvrez travail.html dans le navigateur. Vous devez constater que :

Ce que vous vérifiez Ce que vous devez voir
Le titre principal « Ma première page » s'affiche en gros, en haut de la page
Le paragraphe Votre phrase de présentation s'affiche en dessous
L'onglet du navigateur Il affiche le titre que vous avez choisi. Avant que vous n'écriviez le <title>, il affiche l'adresse du fichier — c'est le navigateur qui bouche le trou, faute de titre
Les accents é, à, ç s'affichent normalement — si vous voyez « Ã© », l'encodage manque

⏱️ Durée indicative

30 à 40 minutes si c'est votre première page web — le temps de lire le cours, de prendre VSCode en main et d'installer la boucle enregistrer / recharger. La frappe elle-même prend 15 minutes.
