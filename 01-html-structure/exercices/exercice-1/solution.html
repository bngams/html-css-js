Le code complet

Afficher le code complet (après avoir essayé !) 
<!DOCTYPE html>
<html lang="fr">
<head>
  <meta charset="UTF-8">
  <title>Mon premier site</title>
</head>
<body>
  <h1>Ma première page</h1>
  <p>
    Bonjour ! J'apprends à créer des pages web.
    Ceci est le tout premier fichier HTML que j'écris à la main.
  </p>
</body>
</html>

Remarquez : le <title> (« Mon premier site ») et le <h1> (« Ma première page ») sont différents. Le premier s'affiche dans l'onglet du navigateur, le second dans la page.

💡 <details> — le bloc dépliant ci-dessus — est du HTML pur, sans une ligne de JavaScript. Vous saurez l'écrire d'ici la fin du projet 2.

Le fichier complet et commenté se trouve dans solution/index.html — ouvrez-le dans VSCode pour lire les commentaires ligne par ligne, ou affichez-le dans le navigateur.

Ligne par ligne

<!DOCTYPE html>

Toujours en première ligne, avant tout le reste. Elle demande au navigateur d'interpréter la page selon les règles du HTML moderne. Sans elle, le navigateur passe en « mode compatibilité » et certains styles se comportent différemment — un bug difficile à diagnostiquer quand on ne connaît pas cette cause.

<html lang="fr">

La balise racine : elle contient tout. L'attribut lang n'a aucun effet visible, mais il sert aux lecteurs d'écran (prononciation), aux moteurs de recherche, et au navigateur (proposition de traduction, césure des mots).

<meta charset="UTF-8">

À placer le plus haut possible dans le <head>. C'est elle qui fait que « créé » s'affiche « créé » et non « crÃ©Ã© ». UTF-8 couvre les accents français, les emojis et la quasi-totalité des langues du monde.

<title>

Le seul élément du <head> que le visiteur perçoit : onglet du navigateur, favoris, et ligne bleue cliquable dans les résultats de recherche.

<h1> et <p>

Un seul <h1> par page : c'est le titre principal du contenu. Les niveaux suivants (h2, h3…) structurent en sous-parties — vous les utiliserez dès l'exercice 2.

Les erreurs fréquentes

Symptôme Cause probable
Les accents s'affichent « Ã© », « Ã » La ligne <meta charset="UTF-8"> manque, ou elle est placée après du contenu
L'onglet affiche « travail.html » La balise <title> manque, ou elle est hors du <head>
Le texte du titre s'affiche, mais pas en gros La balise <h1> n'est pas fermée (</h1> oublié)
Toute la page s'affiche comme un seul bloc de texte Une balise ouvrante n'est pas fermée : le navigateur « avale » la suite

Un outil pour vérifier. Le validateur du W3C accepte votre fichier et liste les erreurs précises, avec le numéro de ligne. Bien plus rapide que de chercher à l'œil.
