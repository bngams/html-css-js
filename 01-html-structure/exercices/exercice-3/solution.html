Attention aux chemins si vous comparez avec le fichier corrigé. Le code ci-dessus est écrit pour travail.html et remonte de deux dossiers (../../assets/). Le fichier solution/index.html est rangé un niveau plus bas et en remonte donc trois (../../../assets/). Même destination, profondeur différente — c'est exactement le piège de la notion 1.

Le fichier complet et commenté est dans solution/index.html — ouvrez-le dans VSCode, ou affichez-le dans le navigateur.

Les erreurs fréquentes

Symptôme Cause probable
À la place de l'image, un texte ou une icône cassée Le chemin est faux. Comptez les ../ : depuis travail.html, il en faut deux pour atteindre assets/
L'image ne s'affiche pas et rien ne la remplace L'attribut alt manque — il n'y a donc aucun texte de remplacement à afficher
La vidéo s'affiche mais sans aucun bouton controls manque. Il s'écrit seul, sans = ni valeur
Le lecteur vidéo reste noir, la carte reste vide Pas de connexion Internet — les deux viennent de sites extérieurs. Ce n'est pas une erreur de votre code
Le SVG n'apparaît pas Une balise interne non fermée : <circle … /> se termine par une barre oblique avant le chevron
La légende s'affiche mais n'est pas liée à l'image Le <figcaption> est en dehors du <figure>
Le validateur signale « An img element must have an alt attribute » Exactement ce qu'il dit : une image sans alt

Le réflexe qui fait gagner du temps sur les chemins : dans VSCode, tapez src=" puis ../ — l'éditeur propose la liste des dossiers disponibles à cet endroit. Si assets n'apparaît pas, c'est que vous n'êtes pas remonté assez haut.
