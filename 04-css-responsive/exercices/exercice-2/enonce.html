Les media queries

  • 📖 Cours
  • 📋 Énoncé
  • ✍️ À vous de jouer
  • ✅ Solution

🎯 Objectif — Faire qu'une même page se réorganise à deux moments précis : à 700 px, puis à 1000 px.

Niveau : débutant. Prérequis : l'exercice 1 de ce projet, et Flexbox (projet 3, exercice 3).

📄 Les fichiers

Fichier Rôle
travail.html 🔒 Fourni et figé
style.css 👉 LE FICHIER QUE VOUS MODIFIEZ — organisé en trois parties, dans l'ordre mobile-first

L'ordre du fichier fait partie de l'exercice. Les règles de base d'abord, les media queries ensuite, par largeur croissante. En CSS, à spécificité égale, la dernière règle écrite gagne : une media query placée trop haut serait écrasée par les règles qui la suivent.

✅ Critères de réussite

Partie 2 — le style de base (petits écrans)

  1. .banniere — fond #14457b, padding: 1rem, texte centré. Sans display: flex
  2. .logo — blanc, gras, 1.3rem, sans marge
  3. .menu — liens côte à côte, passage à la ligne autorisé, centrés, gap: 1rem
  4. .menu a — blancs, sans soulignement
  5. h1 — font-size: 1.6rem

Partie 3 — les enrichissements

  1. @media (min-width: 700px) contenant .banniere : côte à côte, space-between, centré verticalement, padding: 1rem 2rem, text-align: left
  2. Dans la même media query : .grille en flex avec gap: 1rem, et .espace avec margin-bottom: 0
  3. @media (min-width: 1000px), écrite après la précédente, contenant h1 à 2.4rem

🔍 Comment vérifier

Cette page a trois états. Testez-les en faisant varier la largeur — au mode appareil mobile, la largeur s'affiche en haut de la page.

Largeur Ce que vous devez voir
360 px
(téléphone)		 Le logo au-dessus du menu, tous deux centrés · les quatre liens sur une ou deux lignes · les trois espaces empilés, chacun sur toute la largeur · titre de taille modeste
800 px
(tablette)		 Le logo à gauche, le menu à droite, sur la même ligne · les trois espaces côte à côte · le titre n'a pas changé de taille
1200 px
(ordinateur)		 Idem qu'à 800 px, mais le titre est nettement plus grand

Le moment exact des bascules : à 700 px pour la bannière et la grille, à 1000 px pour le titre. Passez lentement de 690 à 710 px pour voir le premier basculement se produire.

🧪 Manip — le sens de min-width

  1. Dans votre media query de l'étape 6, remplacez min-width par max-width. Enregistrez, rechargez.
  2. Testez à 360 px, puis à 1200 px.

Tout est inversé : la bannière s'étale sur le téléphone et s'empile sur l'ordinateur. min-width: 700px signifie « la fenêtre fait au moins 700 px » — donc les grands écrans. C'est le contresens le plus fréquent.

Remettez min-width avant de continuer.

🧪 Manip — pourquoi l'ordre compte

  1. Déplacez la media query de l'étape 8 (celle de 1000 px) avant celle de 700 px. Enregistrez, rechargez.
  2. Regardez le titre à 1200 px.

Il reste petit. À 1200 px les deux media queries s'appliquent, et comme aucune n'est plus spécifique que l'autre, c'est la dernière écrite qui gagne — ici celle de 700 px, qui laisse h1 à 1.6rem. Aucun message d'erreur, juste une règle qui semble ignorée.

Remettez-les dans l'ordre croissant.

🏁 Comment savoir que j'ai fini

  • Les trois états du tableau sont constatés
  • Dans style.css, Ctrl+F sur TODO : plus aucun marqueur en dehors de l'en-tête du fichier
  • Ctrl+F sur @media : exactement deux résultats, le 700 px avant le 1000 px
  • Le validateur CSS du W3C ne signale aucune erreur — il repère notamment une accolade manquante

⏱️ Durée indicative

35 à 45 minutes. Les étapes 1 à 5 vont vite ; l'essentiel du temps se passe à tester les bascules, et c'est le plus instructif.
