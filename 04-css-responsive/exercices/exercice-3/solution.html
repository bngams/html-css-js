Une seule media query — et c'est le but

Comptez : il n'y en a qu'une dans tout le fichier, pour la colonne latérale. Tout le reste s'adapte sans aucun seuil écrit.

Ce qui s'adapte Grâce à
La grille d'événements flex-wrap + flex: 1 1 300px
Le menu de quatre liens flex-wrap: wrap
La taille du titre clamp(1.6rem, 5vw, 2.8rem)
L'image de bannière object-fit: cover + max-width: 100%
La largeur du contenu max-width + margin: 0 auto
La colonne latérale la media query — le seul cas qui l'exigeait

Pourquoi la latérale exige un seuil : les autres éléments peuvent rétrécir jusqu'à une taille acceptable. Une colonne de 260 px à côté du contenu, non : sous une certaine largeur, il faut décider qu'elle passe dessous. C'est un changement de disposition, pas de taille — et c'est exactement ce à quoi servent les media queries.

Le calcul de la base, et pourquoi il compte

flex: 1 1 300px n'a pas été choisi au hasard. La règle : 

n × base + (n − 1) × gap ≤ largeur disponible

À 860 px de fenêtre, la ligne utile fait 828 px (moins les paddings). Trois cartes de 300 px demanderaient 3 × 300 + 2 × 16 = 932 px : elles ne tiennent pas. Deux en demandent 616 : elles tiennent.

Avec une base de 260 px, trois cartes seraient passées (812 ≤ 828) — et la quatrième se serait retrouvée seule sur sa ligne, étirée sur toute la largeur, puisque flex-grow vaut 1. Un résultat déséquilibré, qui ressemble à un bug.

La base n'est pas un minimum : c'est un point de départ. Elle se choisit en faisant ce calcul.

Les erreurs fréquentes

Symptôme Cause probable
L'image de bannière est écrasée, aplatie object-fit: cover manque : height: 180px déforme l'image sans lui
Le titre est minuscule sur téléphone ou énorme sur grand écran vw a été utilisé seul, sans les bornes de clamp()
Trois cartes par ligne, la quatrième seule et étirée La base est trop petite. Refaites le calcul ci-dessus
L'encadré reste sous le contenu même sur grand écran La media query manque, ou display: flex a été posé sur .principal au lieu de .disposition — la règle va sur le parent
L'encadré occupe la moitié de la largeur flex: 0 0 260px a été écrit 1 1 260px : il grandit au lieu de rester fixe
Un écart vertical subsiste au-dessus de l'encadré margin-top: 0 manque dans la media query : la marge de l'étape 8 reste active
Les liens du menu débordent sur téléphone flex-wrap: wrap manque sur .menu
