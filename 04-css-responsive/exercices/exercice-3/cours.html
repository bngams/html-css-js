Projet 4 · Exercice 3

Une page entièrement adaptative

Ce que vous allez apprendre ici : assembler tout ce que vous savez sur une vraie page — et deux outils de plus qui évitent beaucoup de media queries.

C'est le dernier exercice du projet, et le plus proche d'un site réel.

1 · Ce que vous savez déjà

Trois acquis, qui suffisent à l'essentiel :

Outil Rôle Vu en
meta viewport · max-width · unités relatives Faire qu'une page rétrécisse proprement Exercice 1
@media (min-width: …) Réorganiser à partir d'un certain seuil Exercice 2
flex-wrap: wrap · flex: 1 1 … Laisser les éléments passer à la ligne seuls Projet 3

2 · Une grille qui s'adapte sans media query

Vous l'avez croisé au projet 3 sans qu'on en explique la portée. Voici la technique complète : 

.grille {
  display: flex;
  flex-wrap: wrap;
  gap: 1rem;
}

.carte {
  flex: 1 1 300px;
}

Le navigateur place autant de cartes de 300 px qu'il peut sur la ligne, puis renvoie les autres dessous. Sur 1200 px il en met trois, sur 700 px deux, sur 360 px une seule — sans qu'aucun seuil ait été écrit.

C'est le contenu qui décide, pas vous. Une media query fixe un seuil arbitraire ; flex-basis laisse le navigateur calculer. Le second s'adapte aux tailles d'écran que vous n'aviez pas prévues.

Réservez les media queries à ce qui ne peut pas se résoudre ainsi : un menu à transformer, un élément à déplacer, une typographie à changer d'échelle.

3 · Le piège de la valeur de base

La base n'est pas un minimum. Avec flex: 1 1 300px et flex-grow à 1, une carte seule sur sa ligne s'étire sur toute la largeur disponible.

Quatre cartes de base 300 px dans une ligne de 1000 px donnent donc trois cartes puis une seule, étirée — un résultat déséquilibré. Si vous voulez deux par deux, choisissez une base telle que trois ne tiennent pas.

Le calcul, à faire une fois :

largeur disponible ≥ n × base + (n − 1) × gap

Les trois nombres de flex

Vous avez toujours écrit flex: 1 1 300px jusqu'ici. Les deux premiers nombres ne sont pas décoratifs — ils décident du comportement :

Écriture Se lit Usage
flex: 1 1 300px peut grandir · peut rétrécir · part de 300 px Des cartes qui se partagent la place
flex: 1 1 auto peut grandir · peut rétrécir · part de son contenu Une colonne qui prend toute la place restante
flex: 0 0 260px ne grandit pas · ne rétrécit pas · fait 260 px Une colonne de largeur fixe

Les deux dernières formes vont souvent par paire : une colonne latérale figée à 0 0 260px et un contenu principal en 1 1 auto qui absorbe le reste. Vous les emploierez ainsi à l'étape 9.

Pour une ligne de 860 px avec un gap de 16 px : une base de 400 px en laisse passer deux (816 px) mais pas trois (1232 px). Une base de 250 px en laisse passer trois.

4 · Une typographie qui s'adapte — clamp()

Faire grandir un titre par paliers demande une media query par palier. clamp() fait le travail en une ligne : 

h1 {
  font-size: clamp(1.6rem, 5vw, 3rem);
         /*      mini    idéal   maxi  */
}
Valeur Rôle
1.6rem La taille minimale — jamais en dessous
5vw La taille souhaitée — ici 5 % de la largeur de la fenêtre
3rem La taille maximale — jamais au-dessus

Le titre grandit donc continûment avec la fenêtre, en restant lisible sur téléphone et raisonnable sur grand écran. Aucun palier, aucun saut.

N'utilisez jamais vw seul pour du texte : font-size: 5vw donne 18 px sur un téléphone de 360 px — et 96 px sur un écran de 1920. C'est la valeur minimale de clamp() qui rend la technique utilisable.

5 · Une image qui s'adapte — object-fit

Vous savez empêcher une image de déborder (exercice 1). Reste un cas : lui imposer une hauteur fixe sans la déformer. 

.banniere img {
  width: 100%;
  height: 200px;
  object-fit: cover;
}

object-fit: cover demande à l'image de remplir la zone en gardant ses proportions, quitte à rogner les bords. Sans lui, l'image serait écrasée pour entrer dans les 200 px.

6 · Deux propriétés de texte utiles ici

Propriété Effet
text-transform: uppercase Affiche le texte EN MAJUSCULES, sans modifier le HTML — utile pour une date ou une étiquette
font-style: italic Met le texte en italique (vu au projet 4, exercice 1)

text-transform ne change que l'affichage. Le texte reste écrit normalement dans le HTML : il sera copié-collé en minuscules, et lu tel quel par un lecteur d'écran. C'est justement ce qu'on veut — l'inverse de taper les majuscules à la main.

7 · L'ordre de travail, récapitulé

La méthode, du moins coûteux au plus coûteux — et dans cet ordre :

# Étape Outils
1 Poser les fondations meta viewport, max-width, rem, img { max-width: 100% }
2 Laisser le contenu se placer seul flex-wrap, flex-basis, clamp()
3 Réorganiser ce qui résiste @media (min-width: …)

Une page bien construite a deux ou trois media queries, pas dix. Si vous en accumulez, c'est presque toujours le signe qu'une largeur fixe traîne quelque part, ou qu'un flex-basis réglerait le cas.
