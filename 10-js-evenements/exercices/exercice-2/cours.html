Projet 10 · Exercice 2

Écouter pendant qu'on tape

  • 📖 Cours
  • 📋 Énoncé
  • ✍️ À vous de jouer
  • ✅ Solution

Ce que vous allez apprendre ici : réagir à chaque touche frappée, et lire ce que le visiteur a écrit.

Quatre notions nouvelles, toutes courtes : l'événement input, .value, .toLowerCase() et .includes().

1 · Le clic ne suffit plus

À l'exercice 1, l'action était ponctuelle : on clique, il se passe quelque chose. Une recherche, elle, se raffine à chaque lettre — le visiteur n'appuie sur aucun bouton.

addEventListener ne change pas. Seul le nom de l'événement change. C'est toute la logique des événements : un même geste, des déclencheurs différents.

2 · L'événement input

champ.addEventListener("input", function () {
  // appelée à CHAQUE modification du champ
});
ÉvénementSe déclenche…
"click"à chaque clic sur l'élément
"input"à chaque modification d'un champ de saisie

Chaque lettre déclenche un tour. Taper dune appelle la fonction quatre fois : après le d, après le u, après le n, après le e. Effacer la déclenche aussi.

3 · .value — lire ce qui est écrit

champ.value       → ce que le visiteur a tapé, en TEXTE

Ce n'est pas textContent. Un champ de saisie ne contient pas de texte au sens du DOM : ce qu'on y tape vit dans sa propriété .value. 

champ.textContent   → ""            ⚠️ toujours vide
champ.value         → "dune"        ✅ ce qu'on cherche

.value rend toujours du texte, même pour un champ numérique. Pour compter avec, il faudrait Number() — comme au projet 6.

4 · Une fonction qu'on appelle deux fois

La page doit afficher les livres au chargement, puis les refiltrer à chaque frappe. C'est le même travail : on l'écrit une fois, dans une fonction. 

function afficher(filtre) {
  // vider, construire, compter
}

afficher("");                                    ← au chargement : tout

champ.addEventListener("input", function () {
  afficher(champ.value.toLowerCase());           ← à chaque frappe
});

La fonction du projet 7 reprend son rôle premier : éviter d'écrire deux fois la même chose. Le paramètre filtre est ce qui change d'un appel à l'autre.

5 · Chercher un texte dans un texte

Deux outils, chacun d'une ligne :

"Le Nom du vent".toLowerCase()        → "le nom du vent"
"le nom du vent".includes("du")      → true
"le nom du vent".includes("xyz")     → false
MéthodeCe qu'elle rend
.toLowerCase()le même texte, tout en minuscules
.includes(morceau)true ou false — le morceau est-il dedans ?

Sans toLowerCase, la recherche est sensible à la casse — et ce n'est jamais ce qu'un visiteur attend : 

"Dune".includes("du")                        → false   ⚠️ le D majuscule
"Dune".toLowerCase().includes("du")          → true    ✅

Il faut mettre en minuscules les deux côtés : le titre et ce que le visiteur tape. Sinon, taper DU ne trouve plus rien.

.includes() cherche n'importe où dans le texte, pas seulement au début. "Fondation".includes("dation") → true.

6 · Vider avant de reconstruire — encore

C'est le geste du projet 9, exercice 4. Ici il devient vital : la fonction est rappelée à chaque lettre. 

for (const ancien of liste.querySelectorAll("li")) {
  ancien.remove();
}

Sans le ménage, les résultats s'empilent. Taper quatre lettres ajouterait quatre listes à la suite, sans jamais rien retirer.

Et toujours la même règle : on boucle sur querySelectorAll, jamais sur .children, qui est une liste vivante (projet 9, exercice 3, section 3 bis).

7 · Rendre un résultat

La fonction compte au passage. Pour que l'appelant connaisse ce compte, elle le rend — le return du projet 7 : 

function afficher(filtre) {
  let trouves = 0;
  // …
  return trouves;
}

console.log("Au départ :", afficher(""), "livre(s)");

Une fonction qui agit et rend une valeur est courante. Ici elle modifie la page (son effet) et rend le nombre de résultats (sa valeur) — ce qui évite de recompter ailleurs.

8 · ⚠️ Rechargez, puis tapez

Le réflexe de l'exercice 1 vaut toujours : l'écouteur se pose au chargement. Sans F5 après Ctrl+S, vous testez l'ancien code.

Un symptôme reconnaissable : vous corrigez une erreur, elle persiste à l'identique. Rechargez.
