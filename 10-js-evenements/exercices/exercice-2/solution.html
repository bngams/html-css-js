Avez-vous essayé la manip sans le ménage ? C'est elle qui montre pourquoi une fonction rappelée en boucle doit commencer par faire le vide. Si ce n'est pas fait, retournez à la page de travail.

Le fichier complet

Une solution possible. Seuls les critères comptent : une autre écriture qui les remplit tous est tout aussi juste.

Afficher app.js en entier 
const livres = [
  { titre: "La Horde du Contrevent", auteur: "Alain Damasio" },
  { titre: "Dune",                   auteur: "Frank Herbert" },
  { titre: "Fondation",              auteur: "Isaac Asimov" },
  { titre: "Le Nom du vent",         auteur: "Patrick Rothfuss" },
  { titre: "Les Fourmis",            auteur: "Bernard Werber" },
  { titre: "Chroniques martiennes",  auteur: "Ray Bradbury" }
];

/* 1 · Les éléments de la page */

const champ    = document.querySelector("#recherche");
const liste    = document.querySelector("#resultats");
const compteur = document.querySelector("#compteur");

/* 2 · Une fonction qui reconstruit la liste */

function afficher(filtre) {

  for (const ancien of liste.querySelectorAll("li")) {
    ancien.remove();
  }

  let trouves = 0;

  for (const livre of livres) {

    const titre = livre.titre.toLowerCase();

    if (titre.includes(filtre)) {

      const li = document.createElement("li");
      li.classList.add("livre");

      const nom = document.createElement("span");
      nom.classList.add("livre__titre");
      nom.textContent = livre.titre;

      const auteur = document.createElement("span");
      auteur.classList.add("livre__auteur");
      auteur.textContent = livre.auteur;

      li.append(nom, auteur);
      liste.append(li);

      trouves = trouves + 1;
    }
  }

  compteur.textContent = trouves + " livre(s) sur " + livres.length;

  if (trouves === 0) {
    compteur.classList.add("vide");
  } else {
    compteur.classList.remove("vide");
  }

  return trouves;
}

/* 3 · Au chargement : tout afficher */

console.log("Au départ :", afficher(""), "livre(s)");

/* 4 · À chaque frappe : refiltrer */

champ.addEventListener("input", function () {

  const filtre = champ.value.toLowerCase();

  const trouves = afficher(filtre);

  console.log("Recherche :", champ.value, "→", trouves, "résultat(s)");
});

Les quatre choses à retenir

1 · Une fonction, deux appelants

afficher("")                      ← au chargement, une fois
afficher(champ.value.toLowerCase())  ← à chaque frappe

Le filtre vide affiche tout. Ce n'est pas un cas particulier à traiter : "n'importe quoi".includes("") rend true. Un seul chemin de code couvre les deux situations.

2 · La casse, des deux côtés

const titre  = livre.titre.toLowerCase();        ← côté données
const filtre = champ.value.toLowerCase();        ← côté saisie

titre.includes(filtre)
Ce qu'on met en minusculesTaper DU donne
Les deux côtés3 ✅
Le titre seulement0 ❌
La saisie seulement2 ❌ — « Dune » garde son D, mais les deux « du » déjà minuscules passent
Aucun0 ❌

L'affichage, lui, garde la casse d'origine : on met en minuscules pour comparer, pas pour afficher. C'est livre.titre — et non titre — qui est écrit dans la page.

Le bug « saisie seulement » est le plus sournois : il ne se voit pas sur du ni sur DU, qui rendent encore des résultats plausibles. Cherchez dune pour l'attraper — 0 résultat au lieu de 1.

3 · Le ménage en première ligne

La boucle de remove() est la première instruction de la fonction. Comme la fonction est rappelée à chaque lettre, tout oubli se voit immédiatement : 

avec le ménage    →  d : 4 lignes · du : 3 · dun : 1 · dune : 1
sans le ménage    →  d : 10 lignes · du : 13 · dun : 14 · dune : 15   ⚠️

Pourquoi 10 et non 4 ? Les six livres du chargement sont déjà dans la liste et ne sont jamais retirés. Chaque frappe empile les siens par-dessus : 6, puis 6+4, puis +3, puis +1, puis +1.

4 · Une fonction qui agit et qui rend

return trouves;

afficher modifie la page et rend le nombre de résultats. L'appelant s'en sert pour son console.log, sans recompter : 

console.log("Au départ :", afficher(""), "livre(s)");

Une seule source de comptage. Recompter dans l'appelant ouvrirait la porte à deux vérités qui divergent — la même raison qu'au projet 9, exercice 4.

Les erreurs fréquentes

SymptômeCause
Les résultats s'empilent à chaque lettre Le ménage manque au début de la fonction (cours §6)
du trouve 3 livres, DU n'en trouve aucun Un seul des deux côtés est passé en minuscules (cours §5)
Le champ semble toujours vide champ.textContent au lieu de champ.value (cours §3)
Rien ne s'affiche au chargement, tout marche dès qu'on tape L'appel afficher("") au chargement a été oublié
Le compteur reste rouge même quand des livres réapparaissent La classe vide est ajoutée, jamais retirée : il manque le else
Le titre s'affiche tout en minuscules C'est titre (la version comparée) qui est écrit dans la page au lieu de livre.titre

Ce qui vient ensuite

Vous savez réagir à un clic et à une frappe. Dans les deux cas, le navigateur n'a rien fait d'autre que vous prévenir.

À l'exercice 3, l'événement est un envoi de formulaire — et là, le navigateur a un comportement par défaut : recharger la page. Il faudra l'en empêcher.
