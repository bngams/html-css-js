Rechercher un livre

    Ceci est le corrigé en fonctionnement. Ouvrez la console (F12), puis tapez dans le champ.

    Une ligne s'affiche au chargement — les six livres sont déjà là. Chaque touche frappée ajoute ensuite sa propre ligne : essayez du, puis DU, puis xyz.

    Regardez le code source de cette page (clic droit → Afficher le code source) : la liste y est vide. Tout ce que vous voyez est fabriqué, puis refabriqué à chaque frappe.
