Le fichier que vous modifiez : app.js

Les deux boutons sont inertes. Cliquez dessus : il ne se passe rien, et c'est normal — aucun code ne les écoute encore.

La classe allumee est déjà écrite dans le CSS. Votre code n'a qu'à la poser et la retirer : le style suit tout seul.

Avant de commencer

  1. Ouvrez la console : F12 → onglet Console
  2. Ouvrez app.js dans VSCode
  3. Enregistrez avec Ctrl+S, puis rechargez avec F5

Un réflexe à prendre : après chaque modification, rechargez puis cliquez. Un écouteur se pose au chargement de la page — si vous ne rechargez pas, c'est l'ancien code qui écoute encore.
