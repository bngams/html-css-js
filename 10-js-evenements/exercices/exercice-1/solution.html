Avez-vous essayé la manip des parenthèses ? C'est elle qui fait comprendre la différence entre confier une fonction et l'appeler. Si ce n'est pas fait, retournez à la page de travail.

Le fichier complet

Une solution possible. Seuls les critères comptent : une autre écriture qui les remplit tous est tout aussi juste.

Afficher app.js en entier 
/* 1 · Trouver les éléments */

const bouton    = document.querySelector("#allumer");
const lampe     = document.querySelector("#lampe");
const etat      = document.querySelector("#etat");
const compteur  = document.querySelector("#compteur");
const raz       = document.querySelector("#raz");

let clics = 0;

/* 2 · La fonction qui réagit au clic */

function basculer() {
  clics = clics + 1;

  lampe.classList.toggle("allumee");

  if (lampe.classList.contains("allumee")) {
    etat.textContent = "La lampe est allumée";
  } else {
    etat.textContent = "La lampe est éteinte";
  }

  compteur.textContent = clics + " clic(s)";

  console.log("Clic n°", clics, "· allumée ?", lampe.classList.contains("allumee"));
}

/* 3 · Attacher la fonction au bouton */

bouton.addEventListener("click", basculer);

console.log("Écouteur posé sur :", bouton.textContent);

/* 4 · Un second bouton, une fonction anonyme */

raz.addEventListener("click", function () {
  clics = 0;
  compteur.textContent = "0 clic(s)";
  lampe.classList.remove("allumee");
  etat.textContent = "La lampe est éteinte";

  console.log("Remise à zéro");
});

console.log("État initial :", etat.textContent);

Les quatre choses à retenir

1 · Le code s'exécute en deux temps

C'est le point qui déroute le plus. Regardez l'ordre réel : 

AU CHARGEMENT, une seule fois :
  · les cinq querySelector
  · la déclaration de basculer     ← définie, PAS appelée
  · les deux addEventListener      ← écoutes posées
  · les deux console.log           ← les 2 lignes que vous voyez

À CHAQUE CLIC, autant de fois qu'on clique :
  · le corps de basculer           ← appelé par le NAVIGATEUR

Les deux lignes de console au chargement sont la preuve que rien ne s'est encore produit : l'écoute est en place, la fonction attend.

2 · toggle puis contains

toggle bascule la classe, mais ne dit pas dans quel état on atterrit. On le demande ensuite à la page : 

lampe.classList.toggle("allumee");                  ← on bascule
lampe.classList.contains("allumee")   → true/false  ← on relit

Une seule source de vérité. On aurait pu tenir un let allumee = false renversé à la main — mais il aurait fallu le garder d'accord avec la classe, à chaque endroit du code. La page sait déjà : autant la lire.

3 · Le compteur vit hors de la fonction

let clics = 0;         ← HORS de la fonction : survit aux clics

function basculer() {
  clics = clics + 1;   ← 1, 2, 3…
}
Où est let clics = 0Résultat au 3ᵉ clic
Hors de la fonction3 clic(s) ✅
Dans la fonction1 clic(s) ❌ — recréé à chaque appel

4 · Deux écritures, un même geste

Le bouton principal reçoit une fonction nommée ; la remise à zéro, une fonction anonyme. Ce n'est pas une incohérence : ce sont les deux formes du cours §7, montrées côte à côte. 

bouton.addEventListener("click", basculer);          ← nommée

raz.addEventListener("click", function () { … });    ← anonyme

Écrivez les deux de la même façon si vous préférez — les critères ne l'imposent pas. La fonction nommée se justifie quand le code est long ou réutilisé ; l'anonyme, quand il tient en trois lignes.

Les erreurs fréquentes

SymptômeCause
La lampe s'allume au chargement, le bouton principal est inerte addEventListener("click", basculer()) — les parenthèses appellent la fonction au lieu de la confier (cours §3)
Le compteur affiche toujours 1 clic(s) let clics = 0 est dans la fonction : il est recréé à chaque appel (cours §5)
La couleur change, mais le texte dit le contraire Le contains est lu avant le toggle : on relit l'état d'avant la bascule
TypeError: Cannot read properties of null Un identifiant est mal orthographié — ou le <script> ne serait pas en bas du <body> (projet 9, exercice 1)
Rien ne se passe, aucune erreur La page n'a pas été rechargée après l'enregistrement : l'ancien écouteur est encore en place (cours §8)
La remise à zéro laisse la lampe allumée Elle remet le compteur mais oublie classList.remove("allumee")

Ce qui vient ensuite

Vous savez réagir à un clic. Le clic est l'événement le plus simple : il arrive, on agit.

À l'exercice 2, l'événement se répète à chaque touche frappée, et il faudra lire ce que le visiteur a tapé.
