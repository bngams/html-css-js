Projet 10 · Exercice 1

Le premier clic

  • 📖 Cours
  • 📋 Énoncé
  • ✍️ À vous de jouer
  • ✅ Solution

Ce que vous allez apprendre ici : faire réagir votre code à une action du visiteur.

Une seule notion nouvelle : addEventListener. Tout le reste — querySelector, textContent, classList — vient du projet 9.

1 · Jusqu'ici, votre code parlait tout seul

Au projet 9, votre code s'exécutait une fois, au chargement de la page, de haut en bas. Puis il s'arrêtait. La page était construite, et plus rien ne bougeait.

Un visiteur, lui, agit : il clique, il tape, il envoie un formulaire. Il faut donc du code qui ne s'exécute pas tout de suite, mais plus tard — au moment où l'action se produit.

C'est le renversement du projet 10. Vous n'écrivez plus « fais ceci » : vous écrivez « quand ceci arrive, fais cela ». Le moment de l'exécution ne vous appartient plus.

2 · addEventListener — poser une écoute

bouton.addEventListener("click", basculer);

Trois morceaux, dans cet ordre :

MorceauRôle
boutonqui on écoute — un élément trouvé avec querySelector
"click"quoi on attend — le nom de l'événement, entre guillemets
basculerquoi faire — le nom d'une fonction

Cette ligne ne déclenche rien. Elle enregistre une intention : « si un jour on clique sur ce bouton, appelle basculer ». Puis le code continue.

3 · ⚠️ Le nom de la fonction, sans parenthèses

C'est l'erreur numéro un de ce chapitre, et elle ne produit aucun message clair. 

bouton.addEventListener("click", basculer);     ✅ on DONNE la fonction
bouton.addEventListener("click", basculer());   ❌ on l'APPELLE tout de suite

Avec les parenthèses, JavaScript exécute basculer immédiatement, au chargement : la fonction s'exécute maintenant, et le bouton ne reçoit rien à garder. Résultat : la lampe s'allume toute seule au chargement, et le bouton ne fait plus rien.

Une image qui aide : basculer, c'est le numéro de téléphone — vous le confiez pour qu'on appelle plus tard. basculer(), c'est passer le coup de fil maintenant.

4 · La fonction n'est jamais appelée par vous

function basculer() {
  lampe.classList.toggle("allumee");
}

bouton.addEventListener("click", basculer);

Nulle part vous n'écrivez basculer(). C'est le navigateur qui l'appelle, à chaque clic, aussi souvent que le visiteur clique.

La fonction du projet 7 reprend tout son sens. On la définissait pour éviter de réécrire ; ici, on la définit parce qu'on ne sait pas quand elle servira.

5 · Mémoriser entre deux clics

Une variable déclarée hors de la fonction survit d'un clic à l'autre. C'est l'accumulateur du projet 8, dans un nouveau décor : 

let clics = 0;              ← hors de la fonction : mémoire durable

function basculer() {
  clics = clics + 1;        ← 1, puis 2, puis 3…
}

Déclarée à l'intérieur, elle repart de zéro à chaque clic : 

function basculer() {
  let clics = 0;            ⚠️ recréée à chaque appel
  clics = clics + 1;        → toujours 1
}

6 · Lire l'état plutôt que le deviner

classList.toggle pose la classe si elle est absente, la retire si elle est là. Pour savoir dans quel état on vient de tomber, on interroge la page : 

lampe.classList.toggle("allumee");

if (lampe.classList.contains("allumee")) {
  etat.textContent = "La lampe est allumée";
} else {
  etat.textContent = "La lampe est éteinte";
}

toggle et contains viennent du projet 9, exercice 2. Rien de neuf : seul le moment où on les appelle a changé.

On aurait pu garder un let allumee = false et le renverser soi-même. Interroger la page évite d'entretenir deux vérités qui peuvent diverger.

7 · Une fonction sans nom

Quand le code ne sert qu'à un seul écouteur, on peut l'écrire directement à la place du nom : 

raz.addEventListener("click", function () {
  clics = 0;
  compteur.textContent = "0 clic(s)";
});
FormeQuand la préférer
Fonction nommée Le code est long, ou réutilisé par plusieurs écouteurs
Fonction anonyme Deux ou trois lignes, utilisées une seule fois

Les deux formes font exactement la même chose. Ce n'est pas une progression — la seconde n'est ni plus moderne ni plus savante : c'est un choix de lisibilité, et vous croiserez les deux dans du vrai code.

8 · ⚠️ Rechargez, puis cliquez

Un écouteur se pose au chargement de la page. Si vous modifiez app.js sans recharger, c'est l'ancien code qui écoute encore — vous testez une version qui n'existe plus.

Le réflexe, à chaque essai : Ctrl+S, puis F5, puis cliquez.
