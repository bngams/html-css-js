Enregistrer un emprunt

    Le fichier que vous modifiez : app.js

    Il contient déjà le tableau de données — trois emprunts. Mais contrairement aux exercices précédents, ce tableau va grandir : chaque envoi du formulaire y ajoute une ligne.

    Essayez le formulaire maintenant, avant d'écrire une seule ligne. Tapez un titre, appuyez sur Entrée : la page se recharge, le champ se vide, rien n'est enregistré. Vous venez de voir le problème que cet exercice résout.

    Avant de commencer

    1. Ouvrez la console : F12 → onglet Console
    2. Ouvrez app.js dans VSCode
    3. Enregistrez avec Ctrl+S, puis rechargez avec F5

    Attention : quand la page se recharge, la console se vide aussi. Si vos messages disparaissent à l'envoi du formulaire, c'est justement le signe que le rechargement n'a pas été empêché.
