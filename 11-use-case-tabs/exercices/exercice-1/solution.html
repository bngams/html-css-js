Le système d'onglets

Avez-vous essayé la manip « n'éteindre que les panneaux » ? C'est elle qui montre qu'un composant peut afficher juste et mentir sur son état. Si ce n'est pas fait, retournez à la page de travail.

▶ Voir le corrigé en fonctionnement

Le fichier complet

Une solution possible. Seuls les critères comptent : une autre écriture qui les remplit tous est tout aussi juste.

Afficher app.js en entier 
/* 1 · Les deux collections */

const onglets  = document.querySelectorAll(".tab");
const panneaux = document.querySelectorAll(".tab-content");

console.log("Onglets :", onglets.length, "· Panneaux :", panneaux.length);

/* 2 · La fonction qui active un onglet */

function activer(onglet) {

  // a · tout éteindre — les onglets ET les panneaux
  for (const autre of onglets) {
    autre.classList.remove("tab-active");
  }
  for (const panneau of panneaux) {
    panneau.classList.remove("active");
  }

  // b · allumer l'onglet cliqué
  onglet.classList.add("tab-active");

  // c · retrouver SON panneau, par l'attribut data-content-id
  const identifiant = onglet.getAttribute("data-content-id");
  const panneau = document.querySelector("#" + identifiant);

  // d · l'allumer, s'il existe
  if (panneau) {
    panneau.classList.add("active");
  }

  console.log("Onglet :", onglet.textContent, "→ panneau :", identifiant);
}

/* 3 · Un écouteur par onglet */

for (const onglet of onglets) {
  onglet.addEventListener("click", function () {
    activer(onglet);
  });
}

/* 4 · Au chargement : le premier onglet est ouvert */

activer(onglets[0]);

Les cinq choses à retenir

1 · Éteindre tout, sans se demander quoi

for (const autre of onglets)  { autre.classList.remove("tab-active"); }
for (const panneau of panneaux) { panneau.classList.remove("active"); }

Retirer une classe absente ne coûte rien et ne lève aucune erreur. C'est ce qui permet d'éteindre aveuglément : pas besoin de savoir ce qui était allumé, donc pas de mémoire à maintenir.

L'alternative — se souvenir de l'onglet précédent dans une variable — marcherait aussi, mais créerait une deuxième vérité à garder d'accord avec la page. La même raison qu'au projet 10, exercice 1, pour préférer contains à un booléen maison.

2 · Deux boucles, deux collections

CollectionClasse retiréeSi on l'oublie
ongletstab-active plusieurs onglets soulignés — l'état affiché est faux
panneauxactive plusieurs panneaux empilés — le contenu est faux

Les deux oublis sont indépendants et ne produisent pas le même symptôme. C'est ce que montre la manip de l'énoncé.

3 · Du texte vers un élément

onglet.getAttribute("data-content-id")   → "content2"        du TEXTE
"#" + "content2"                         → "#content2"       un SÉLECTEUR
document.querySelector("#content2")      → l'élément         un ÉLÉMENT

Le dièse n'est pas décoratif. Sans lui, querySelector("content2") cherche une balise <content2>, qui n'existe pas : le résultat est null, et le if empêche l'erreur — mais rien ne s'affiche.

4 · Une fonction, deux appelants

activer(onglets[0]);        ← au chargement, une fois

onglet.addEventListener("click", function () {
  activer(onglet);          ← à chaque clic
});

C'est le geste du projet 10, exercice 2, appliqué à un composant. L'ouverture initiale n'est pas un cas particulier : c'est une activation comme les autres, d'où la ligne Onglet : Catalogue → panneau : content1 qui apparaît avant tout clic.

5 · Le JS décide de l'état, le CSS de l'apparence

Inspectez la page en cliquant : seules les classes bougent. Aucun attribut style n'est jamais écrit. 

<button class="tab tab-active">        ← après clic
<div id="content2" class="tab-content active">

Pourquoi classList plutôt que .style ? Parce qu'un style en ligne écrase le CSS et ne peut plus être corrigé par lui : votre JavaScript imposerait une apparence que la feuille de style ne pourrait plus reprendre. C'est la règle du projet 9, exercice 2, section 5.

(Un détail, pour les curieux : .style est même marginalement plus rapide, le navigateur n'ayant pas à réévaluer quelles règles s'appliquent. Ça ne change rien à la conclusion.)

Les erreurs fréquentes

SymptômeCause
Au chargement, la zone de contenu est vide L'appel activer(onglets[0]) manque : le composant démarre sans onglet ouvert (cours §7)
Les panneaux s'empilent, plusieurs visibles La boucle qui retire active manque
Le contenu est bon, mais plusieurs onglets restent bleus La boucle qui retire tab-active manque
Rien ne s'affiche au clic Le "#" manque devant l'identifiant : querySelector rend null. Avec un if (panneau), l'échec est silencieux ; sans lui, vous verrez TypeError: … (reading 'classList')
Le même panneau s'affiche pour tous les onglets L'identifiant est lu une seule fois, hors de la fonction, au lieu d'être relu pour l'onglet cliqué
TypeError: Cannot read properties of undefined (reading 'classList') onglets[0] sur une collection vide : le sélecteur .tab est mal orthographié. La console affiche d'abord Onglets : 0 — le compte est votre premier indice
