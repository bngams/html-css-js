Le système d'onglets

  • 📖 Cours
  • 📋 Énoncé
  • ✍️ À vous de jouer
  • ✅ Solution

🎯 Objectif — Faire fonctionner le tableau de bord de la médiathèque : trois onglets, trois vues, une seule visible à la fois.

Prérequis : les projets 9 et 10 en entier. Une seule notion nouvelle : getAttribute (cours §4).

Un seul fichier : exercices/exercice-1/app.js

Il est vide. La page contient trois boutons et trois panneaux, tous en place, et un CSS complet.

Au chargement, la zone de contenu est vide.

C'est normal : le CSS cache tous les panneaux (.tab-content { display: none }). C'est à votre code d'en ouvrir un — voir le critère 5.

✅ Les critères d'acceptation

Le comportement

  1. Un clic sur un onglet affiche son panneau — celui dont l'id correspond à l'attribut data-content-id du bouton
  2. Un seul panneau est visible à la fois. Les deux autres sont cachés, quel que soit l'ordre des clics
  3. Un seul onglet est souligné à la fois : celui qui vient d'être cliqué porte la classe tab-active, les autres ne l'ont plus
  4. On peut cliquer autant de fois qu'on veut, dans n'importe quel ordre, y compris deux fois de suite sur le même onglet — l'affichage reste cohérent
  5. Au chargement, sans aucun clic, le premier onglet (Catalogue) est déjà souligné et son panneau déjà visible

La manière

  1. Votre code ne contient ni couleur, ni display, ni .style : uniquement des classes posées et retirées
  2. Le lien entre un onglet et son panneau passe par l'attribut data-content-id — pas par la position dans la page

Dans la console

  1. Au chargement : Onglets : suivi du nombre d'onglets, · Panneaux : suivi du nombre de panneaux
  2. À chaque activation — clic et ouverture initiale : Onglet :, le texte du bouton, → panneau :, puis l'identifiant du panneau affiché

🔍 Comment vérifier

Rechargez. Avant tout clic, la console affiche exactement ces deux lignes : 

Onglets : 3 · Panneaux : 3
Onglet : Catalogue → panneau : content1

La deuxième ligne est le test du critère 5. Si elle n'apparaît pas, votre composant démarre sur du vide : il manque l'appel d'ouverture (cours §7).

Cliquez ensuite sur Retards, puis sur Emprunts. La console ajoute : 

Onglet : Retards → panneau : content3
Onglet : Emprunts → panneau : content2

Et la page doit se comporter ainsi :

🧪 Manip — n'éteindre que les panneaux

Une fois l'exercice terminé, essayez volontairement ceci :

  1. Mettez en commentaire la boucle qui retire tab-active des onglets — en gardant celle des panneaux.
  2. Enregistrez, rechargez, cliquez sur les trois onglets à la suite.

Le contenu affiché reste correct, mais les trois onglets finissent soulignés en même temps. Aucune erreur rouge. Le composant affiche une chose et en prétend une autre.

Remettez ensuite la boucle.

🏁 Comment savoir que j'ai fini

  • Les trois onglets basculent, dans n'importe quel ordre
  • Un seul panneau visible, un seul onglet souligné, toujours
  • Le catalogue est ouvert dès le chargement
  • Votre app.js ne contient ni couleur ni display
  • Vous savez dire pourquoi on éteint tout avant de rallumer

⏱️ Durée indicative

45 à 60 minutes. Le code fait une vingtaine de lignes. Écrivez d'abord l'activation d'un seul onglet en dur, vérifiez qu'elle fonctionne, puis entourez-la d'une boucle et d'un écouteur.
