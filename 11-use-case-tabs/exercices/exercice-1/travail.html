Le fichier que vous modifiez : app.js

Les trois onglets sont inertes et la zone de contenu est vide. Cliquez : il ne se passe rien, aucun panneau n'apparaît. C'est normal, aucun code ne les écoute encore.

Le CSS est déjà complet. Il sait afficher un panneau qui porte la classe active, et souligner un onglet qui porte la classe tab-active. Votre code ne décide pas de l'apparence : il décide de l'état.

Avant de commencer

  1. Ouvrez la console : F12 → onglet Console
  2. Ouvrez app.js dans VSCode
  3. Enregistrez avec Ctrl+S, puis rechargez avec F5

Inspectez un panneau (clic droit → Inspecter) pendant que vous cliquez sur les onglets : vous verrez la classe active apparaître et disparaître. C'est tout ce que fait votre code.
