Ce sont des idées, pas un modèle à copier. Les quatre pages ci-dessous sont volontairement très différentes — en sujet, en couleurs, en disposition — pour vous montrer l'étendue de ce qui est faisable avec ce que vous savez déjà.

Regardez-les, redimensionnez-les, ouvrez leur code source si un détail vous intrigue. Puis faites autre chose.

Les trois exemples

Page Ce qu'elle montre
🎨 Portfolio Une page personnelle sobre : photo, parcours, réalisations en grille, contact. Palette neutre, beaucoup d'espace blanc
🚀 Page de présentation Une association qui se présente : accroche, trois arguments, tableau de tarifs, formulaire d'adhésion. Couleurs vives, blocs contrastés
🎪 Page d'événement Un festival : bandeau, programme en liste ordonnée, informations pratiques en tableau. Fond sombre, mise en page dense
📊 Rapport chiffré Un bilan annuel : un graphique en SVG écrit dans la page, un tableau de données et un lien vers un PDF. Sobre, une seule couleur d'accent

Les trois premières respectent les 17 points de la checklist — c'est d'ailleurs un bon exercice de lecture : ouvrez-en une et retrouvez-y les balises sémantiques, la media query, le alt de l'image.

Le rapport chiffré fait exception sur un point, et volontairement : il n'a pas de <img>, mais un graphique SVG écrit directement dans la page. Son équivalent du alt s'écrit alors avec role="img" et des balises <title> et <desc> à l'intérieur du SVG — ouvrez son code, c'est instructif.

Ce qu'elles ont en commun

Malgré leurs différences d'apparence, les quatre partagent la même ossature — celle des projets 1 à 4 :

  • un squelette valide avec meta viewport ;
  • les quatre régions sémantiques ;
  • une feuille de style externe, des classes nommées par leur rôle ;
  • box-sizing, img { max-width: 100% }, des max-width ;
  • une grille en Flexbox qui se réorganise seule ;
  • une seule media query, en mobile-first.

Autrement dit : vous savez déjà tout ce qu'il faut pour en écrire une.
