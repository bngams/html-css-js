Afficher app.js en entier 
const catalogue = [
  { titre: "La Horde du Contrevent", pages: 712 },
  { titre: "Dune", pages: 900 },
  { titre: "Fondation", pages: 420 },
  { titre: "Le Nom du vent", pages: 850 },
  { titre: "Les Fourmis", pages: 300 }
];

document.querySelector("#vide").remove();

const liste = document.querySelector("#catalogue");

console.log("Au départ :", liste.children.length, "élément(s)");

let volumineux = 0;

for (const livre of catalogue) {

  const li = document.createElement("li");
  li.classList.add("livre");

  const titre = document.createElement("span");
  titre.classList.add("livre__titre");
  titre.textContent = livre.titre;

  const pages = document.createElement("span");
  pages.classList.add("livre__pages");
  pages.textContent = livre.pages + " pages";

  li.append(titre, pages);

  if (livre.pages > 700) {
    li.classList.add("volumineux");
    volumineux = volumineux + 1;
  }

  liste.append(li);
}

console.log("Lignes créées :", liste.children.length);
console.log("Volumineux :", volumineux);

let totalPages = 0;

for (const livre of catalogue) {
  totalPages = totalPages + livre.pages;
}

const total = document.createElement("li");
total.textContent = "Total : " + totalPages + " pages";
liste.append(total);

console.log("Total des pages :", totalPages);

console.log("Titres en place :", liste.querySelectorAll(".livre__titre").length);

Les quatre choses à retenir

1 · Fabriquer, remplir, puis insérer

Chaque carte se construit dans cet ordre :

createElement("li")       ← l'élément existe, invisible
li.classList.add(…)       ← on le prépare
li.append(titre, pages)   ← on le remplit (deux d'un coup, cours §3)
liste.append(li)          ← ALORS il apparaît

append(titre, pages) est un raccourci, pas une obligation : li.append(titre) puis li.append(pages) donnent exactement le même résultat. Seuls les critères comptent.

On assemble hors de la page, on n'insère qu'à la fin. Tant que le <li> n'est pas dans la liste, on peut le manipuler tranquillement : rien ne s'affiche, rien ne clignote.

2 · Le createElement DANS la boucle

C'est l'erreur qui coûte le plus cher sur ce chapitre. Sorti de la boucle, il ne fabrique qu'un seul élément. Et comme append déplace au lieu de copier, ce même élément est promené cinq fois — pour finir à un seul endroit. 

createElement hors boucle  →  UNE ligne, portant le dernier titre
createElement dans boucle  →  CINQ lignes                    ✅

Un tour de boucle, un élément neuf. C'est la règle.

3 · Cinq enfants, puis six

Momentchildren.length
Au départ0 — la liste est vide dans le HTML
Après la boucle5 — un par livre
Après le total6

Le critère 6 demande le compte après la boucle, donc 5. Affiché plus bas, il donnerait 6 — la ligne de total s'étant ajoutée entre-temps.

4 · Un élément fabriqué est un élément comme les autres

La dernière ligne du corrigé le prouve : 

liste.querySelectorAll(".livre__titre").length    → 5

querySelectorAll de l'exercice 1 retrouve les éléments que vous venez de fabriquer. Une fois insérés, rien ne les distingue de ceux écrits à la main dans le HTML.

Le code source de la page, lui, reste vide — ce que vous voyez n'existe que dans le DOM, en mémoire. Rechargez : tout est reconstruit.

Les erreurs fréquentes

SymptômeCause
Rien ne s'affiche, aucune erreur Les éléments sont fabriqués mais jamais insérés : il manque append (cours §2)
Une seule ligne, avec le dernier titre Le createElement est hors de la boucle — append a déplacé le même élément cinq fois
Les cartes n'ont ni encadré ni mise en page La classe livre n'a pas été posée sur le <li>
Le titre et les pages sont collés sur une seule ligne de texte Vous avez écrit li.textContent = … au lieu de créer deux <span>
TypeError: Cannot read properties of null #vide a déjà été retiré et vous le cherchez à nouveau — ou un sélecteur est mal orthographié
Lignes créées : 6 Le compte est affiché après l'ajout du total : remontez-le juste après la boucle
