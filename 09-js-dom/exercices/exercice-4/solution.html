Le fichier complet

Une solution possible. Seuls les critères comptent : une autre écriture qui les remplit tous est tout aussi juste.

Afficher app.js en entier 
const emprunts = [
  { titre: "La Horde du Contrevent", lecteur: "Amina",  jours: 3  },
  { titre: "Dune",                   lecteur: "Karim",  jours: 21 },
  { titre: "Fondation",              lecteur: "Léa",    jours: 14 },
  { titre: "Le Nom du vent",         lecteur: "Amina",  jours: 45 },
  { titre: "Les Fourmis",            lecteur: "Tomas",  jours: 8  },
  { titre: "Chroniques martiennes",  lecteur: "Léa",    jours: 30 }
];

/* 1 · Le ménage */

const liste = document.querySelector("#emprunts");

for (const ancien of liste.querySelectorAll("li")) {
  ancien.remove();
}

console.log("Après le ménage :", liste.children.length, "élément(s)");

/* 2 · La construction */

let enRetard = 0;

for (const emprunt of emprunts) {

  const li = document.createElement("li");
  li.classList.add("emprunt");

  const titre = document.createElement("span");
  titre.classList.add("emprunt__titre");
  titre.textContent = emprunt.titre;

  const lecteur = document.createElement("span");
  lecteur.classList.add("emprunt__lecteur");
  lecteur.textContent = emprunt.lecteur;

  const duree = document.createElement("span");
  duree.classList.add("emprunt__jours");
  duree.textContent = emprunt.jours + " jours";

  li.append(titre, lecteur, duree);

  if (emprunt.jours > 28) {
    li.classList.add("retard");
    enRetard = enRetard + 1;
  }

  liste.append(li);
}

console.log("Lignes construites :", liste.children.length);
console.log("En retard :", enRetard);

/* 3 · Relire la page */

let totalJours = 0;

for (const ligne of liste.querySelectorAll(".emprunt__jours")) {
  totalJours = totalJours + Number(ligne.textContent.split(" ")[0]);
}

console.log("Total des jours :", totalJours);

const moyenne = Math.round(totalJours / emprunts.length);
console.log("Durée moyenne :", moyenne, "jours");

/* 4 · Le bandeau */

const bandeau = document.querySelector("#bilan");
bandeau.textContent = emprunts.length + " emprunts, dont " + enRetard + " en retard";

if (enRetard > 0) {
  bandeau.classList.add("alerte");
}

console.log("Bandeau :", bandeau.className);

Les quatre choses à retenir

1 · Le ménage d'abord, toujours

La première ligne de console n'est pas décorative : elle prouve que le ménage a eu lieu avant la construction. 

Après le ménage : 0 élément(s)   ✅ la liste est bien vide
Après le ménage : 3 élément(s)   ❌ le remove() n'a rien fait
Après le ménage : 6 élément(s)   ❌ vous avez construit avant de vider

Placer un affichage à un moment précis est une technique de débogage, pas une exigence de l'énoncé. Vous venez de l'utiliser sans qu'on vous le dise : un compteur bien placé remplace dix minutes de relecture.

2 · Une boucle qui fait deux choses

La boucle de construction pose la classe retard et incrémente le compteur, au même endroit : 

if (emprunt.jours > 28) {
  li.classList.add("retard");   ← ce qu'on voit
  enRetard = enRetard + 1;      ← ce qu'on compte
}

L'affichage et le compte ne peuvent alors pas diverger. Avec deux boucles séparées et deux conditions écrites deux fois, il suffit d'en modifier une pour que le bandeau mente.

3 · Relire la page, pas les données

Le total aurait pu se calculer sur le tableau. L'énoncé demande de le lire dans la page : 

for (const ligne of liste.querySelectorAll(".emprunt__jours")) {
  totalJours = totalJours + Number(ligne.textContent.split(" ")[0]);
}
ÉtapeValeur
ligne.textContent"30 jours" — du texte
.split(" ")["30", "jours"] — un tableau
[0]"30" — toujours du texte
Number(…)30 — enfin un nombre

Les deux méthodes donnent 121 ici, et c'est rassurant : la page dit bien ce que disent les données. Elles divergeront au projet 10, quand l'utilisateur modifiera la page après sa construction.

4 · La moyenne est arrondie

121 / 6            → 20.166666666666668
Math.round(…)      → 20

Math.round vient du projet 6. Sans lui, le bandeau afficherait seize décimales — ce que personne ne veut lire.

Les erreurs fréquentes

SymptômeCause
Neuf lignes s'affichent : trois grises puis six Le ménage manque, ou il boucle sur autre chose que les li
La page est vide, et la console annonce 0 alors que la boucle a construit six éléments Le ménage est placé après la construction : il efface vos propres lignes
Après le ménage : 3 élément(s) La boucle de remove() parcourt .children, qui est vivant — voir exercice 3, section 3 bis
Total des jours : NaN Number("30 jours") sans .split(" ")[0]
Durée moyenne : 20.166666666666668 Math.round oublié
Le bandeau est rouge alors qu'il n'y a aucun retard La classe alerte est posée sans condition, hors du if

Ce que vous savez faire maintenant

Vous venez d'écrire, sans notion nouvelle, le schéma qui porte la plupart des interfaces web : des données en entrée, une page en sortie.

Il manque encore une chose : réagir à l'utilisateur. Pour l'instant, votre page se construit une fois, au chargement, et ne bouge plus. C'est l'objet du projet 10.
