Les quatre choses à retenir

1 · Aucune couleur dans le JavaScript

C'est le critère le plus important, et il ne se voit pas à l'écran. Le corrigé fait changer quatre couleurs sans en nommer une seule : il pose des classes, et le CSS fait le reste.

Conséquence concrète : pour changer le vert du bandeau, on modifie une ligne de CSS. Avec .style, il aurait fallu retrouver l'endroit dans le JavaScript.

2 · Texte et classes sont indépendants

bandeau.textContent = "Médiathèque ouverte";   ← le TEXTE
bandeau.classList.add("ouvert");               ← l'APPARENCE

Deux gestes distincts, sur le même élément. Changer le texte ne touche pas aux classes, et poser une classe ne change pas le texte. C'est pourquoi le critère 2 demande les deux.

3 · Le nombre caché dans le texte

La page affiche 712 pages. Number() seul échoue : 

Number("712 pages")               → NaN     ⚠️
Number("712 pages".split(" ")[0]) → 712     ✅

.split(" ") rend un tableau — ["712", "pages"] — et l'on prend sa première case. Un tableau, un index à partir de zéro : le projet 8, appliqué à du texte.

4 · toggle agit et répond

AppelEffetValeur rendue
1er toggle("ferme") la classe est ajoutée true
2e toggle("ferme") la classe est retirée false

Deux appels de suite ramènent donc à l'état de départ — le bandeau finit sans la classe ferme, et reste vert grâce à ouvert.

La valeur rendue répond à la question « est-elle là maintenant ? ». C'est ce qui rend toggle pratique pour un bouton qui ouvre et ferme : on sait dans quel état on vient de basculer.

Les erreurs fréquentes

SymptômeCause
Rien ne change, aucune erreur Le = manque : vous lisez .textContent au lieu de lui affecter une valeur
TypeError: livres.classList is undefined classList appelé sur la liste au lieu de chaque élément — il faut une boucle
La classe ne s'applique pas Vous avez écrit classList.add(".ouvert") avec le point : le nom de la classe s'écrit sans
Volumineux : 0 Number("712 pages") rend NaN, et NaN > 700 est faux. Il faut découper le texte d'abord
Volumineux : 5 La classe est posée hors du if — chaque livre la reçoit
Le fond ne revient pas après un essai avec .style Un style en ligne neutralise la classe. Videz-le : el.style.backgroundColor = ""
