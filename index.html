Formation · 3 jours

HTML · CSS · JavaScript

Créer des pages web de A à Z, sans rien installer d'autre qu'un éditeur et un navigateur. Chaque projet est indépendant : un cours, des exercices à compléter, et leurs corrigés commentés.

Jour 1 — HTML et CSS

  • Projet 1 Structure d'une page HTML 🎯 doctype · titres · liens · images · médias
  • Projet 2 Sémantique et formulaires 🎯 header/main/article · tableaux · formulaires
  • Projet 3 CSS — la mise en forme 🎯 sélecteurs · box model · Flexbox · vos propres classes
  • Projet 4 CSS — le responsive 🎯 viewport · media queries · mobile-first
  • Projet 5 Projet libre 🎯 votre page, votre thème

Jour 2 — JavaScript, les bases

  • Projet 6 Découvrir JavaScript 🎯 la console · alert/prompt · let/const · charger un script
  • Projet 7 Décider et regrouper 🎯 if/else · fonctions · et/ou/non · un jeu complet
  • Projet 8 Répéter et ranger 🎯 boucles · tableaux · objets · classes

Jour 3 — Pages dynamiques

  • Projet 9 Manipuler la page (DOM) 🎯 sélecteurs · modifier · créer · construire depuis des données
  • Projet 10 Les événements 🎯 click · input · submit · preventDefault
  • Projet 11 Cas pratique — les onglets 🎯 un composant complet · data-* · classList
  • Projet 12 Cas pratique — tableau dynamique 🎯 tableau · formulaire · statut calculé · bonus fetch

Comment travailler : ouvrez un projet, lisez son cours, puis l'énoncé, complétez le fichier qu'il désigne, et comparez avec la solution — après avoir cherché.

Le fichier à modifier change selon le projet — travail.html aux projets 1 et 2, style.css aux projets 3 et 4, script.js au projet 6, puis app.js à partir du projet 7. L'énoncé de chaque exercice le nomme explicitement, et la page de travail vous le rappelle.

Un projet marqué en cours est ouvrable, mais tous ses exercices ne sont pas encore écrits. Ceux marqués « à venir » ne sont pas disponibles.
