Projet 6 · Exercice 1

La console du navigateur

  • 📖 Cours
  • 📋 Énoncé
  • 🖥️ Bac à sable
  • ✅ Solution

Ce que vous allez apprendre ici : ce qu'est JavaScript, où il s'exécute, et comment lui parler directement — sans écrire le moindre fichier.

1 · Le troisième langage

Vous en connaissez déjà deux. Voici la répartition des rôles :

Langage Répond à la question Exemple
HTML Qu'est-ce que c'est ? « ceci est un bouton »
CSS À quoi ça ressemble ? « il est bleu et arrondi »
JavaScript Que fait-il ? « au clic, il affiche le prix »

HTML et CSS décrivent. JavaScript, lui, exécute des instructions : il calcule, il décide, il modifie la page pendant que le visiteur la regarde.

Une différence de nature : une erreur de CSS passe inaperçue — la règle est ignorée, la page s'affiche quand même. Une erreur de JavaScript arrête le programme. C'est déroutant au début, mais c'est aussi une chance : le navigateur vous dit précisément ce qui ne va pas.

2 · Où s'exécute JavaScript

Dans le navigateur du visiteur, sur sa machine. Pas sur un serveur. C'est ce qui permet à une page de réagir instantanément à un clic, sans rien redemander à Internet.

Chaque navigateur embarque un moteur JavaScript qui lit et exécute le code. Et ce moteur est accessible directement : c'est la console.

3 · La console — votre bac à sable

La console est une ligne de commande intégrée au navigateur. Vous y tapez une instruction, vous appuyez sur Entrée, le résultat s'affiche aussitôt.

Navigateur Comment l'ouvrir
Chrome / Edge F12, puis l'onglet Console
Firefox F12, puis l'onglet Console
Safari Cmd+Alt+C — à activer d'abord dans Réglages → Avancés → Afficher le menu Développement

Sur tous les navigateurs, clic droit sur la page → Inspecter fonctionne aussi. C'est le même panneau que vous utilisez depuis le projet 3 pour le CSS — vous ouvrez simplement un autre onglet.

Rien de ce que vous tapez dans la console n'est enregistré. Rechargez la page, tout disparaît. C'est précisément ce qui en fait un endroit sûr pour essayer : vous ne pouvez rien casser.

4 · Votre première instruction

Tapez ceci dans la console, puis Entrée :

2 + 3

La console affiche 5. Vous venez d'exécuter du JavaScript.

Elle est d'abord une calculatrice, et comprend les opérateurs habituels :

Opérateur Effet Exemple
+ addition 7 + 3 → 10
- soustraction 7 - 3 → 4
* multiplication 7 * 3 → 21
/ division 7 / 2 → 3.5
% reste de la division 7 % 3 → 1

Le séparateur décimal est le POINT, jamais la virgule. 3.5 est un nombre ; 3,5 est autre chose et vous donnera un résultat inattendu. C'est la convention de tous les langages de programmation.

5 · Le texte : les chaînes de caractères

Un texte s'écrit entre guillemets — simples ou doubles, au choix, mais les mêmes des deux côtés : 

"Bonjour"
'Bonjour'

Et le + les assemble, au lieu de les additionner :

"Bon" + "jour"        → "Bonjour"
"Il est " + 14 + " h" → "Il est 14 h"

Sans guillemets, ce n'est pas du texte. Taper Bonjour seul fait chercher au navigateur une variable nommée « Bonjour » — qui n'existe pas. Il répond alors Uncaught ReferenceError: Bonjour is not defined.

Cette erreur est votre amie : elle dit exactement ce qui manque. Vous la verrez souvent, et ce n'est pas grave.

6 · Lire ce que répond la console

Trois sortes de réponses, à savoir distinguer :

Ce que vous voyez Ce que ça veut dire
Une valeur (5, "Bonjour") Le résultat de votre instruction
undefined L'instruction a fonctionné mais ne renvoie rien — c'est normal, pas une erreur
Un message en rouge Une erreur : le navigateur explique ce qui cloche

undefined n'est pas une erreur. C'est la réponse normale d'une instruction qui agit sans rien retourner — afficher un message, par exemple. Beaucoup de débutants s'en inquiètent pour rien.
