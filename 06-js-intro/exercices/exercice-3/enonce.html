Des variables et des calculs

🎯 Objectif — Choisir entre let et const, savoir de quel type est une valeur, et faire des calculs fiables avec Math.

Prérequis : l'exercice 2 — les boîtes de dialogue et console.log().

Un seul fichier : exercices/exercice-3/script.js

La page travail.html est fournie et figée : n'y touchez pas.

⚠️ Changement par rapport à l'exercice 2 : aucune boîte de dialogue. Tout s'affiche dans la console.

Si vous ne l'ouvrez pas (F12), vous croirez que rien ne fonctionne. La page, elle, restera vide du début à la fin — c'est normal.

✅ Le travail — 16 étapes

Chaque étape correspond à un marqueur TODO dans script.js. Traitez-les dans l'ordre.

Partie 1 — const ou let ?

  1. Créer NOM_MEDIATHEQUE contenant Médiathèque des Trois Rivières, avec le mot-clé qui interdit le changement (celui qui crée une constante)
  2. Créer PRIX_ABONNEMENT contenant 24, même mot-clé
  3. Créer nombreEmprunts démarrant à 0, avec le mot-clé qui autorise le changement (celui qui crée une variable modifiable)
  4. Donner la valeur 3 à nombreEmprunts, sans réécrire le mot-clé
  5. Ajouter 1 au compteur en vous servant de sa valeur actuelle → doit valoir 4
  6. Afficher dans la console le texte Emprunts : puis nombreEmprunts

Partie 2 — les types

  1. Afficher, en une seule instruction, le type de NOM_MEDIATHEQUE, PRIX_ABONNEMENT et nombreEmprunts → vous devez obtenir string number number

Partie 3 — des calculs avec Math

  1. Ranger dans moyennePages la moyenne de 312, 247 et 190
  2. Afficher le texte Moyenne brute : puis moyennePages
  3. Ranger dans moyenneArrondie cette moyenne arrondie à l'entier le plus proche
  4. Afficher le texte Moyenne arrondie : puis moyenneArrondie
  5. Afficher le texte Le plus long : puis le plus grand des trois nombres, obtenu avec Math et non à la main
  6. Ranger dans prixTTC le prix de l'abonnement augmenté de 20 % (multiplier par 1.2)
  7. Afficher le texte Prix TTC :, puis prixTTC formaté à deux décimales, puis le texte €
  8. Ranger dans gagnant un entier au hasard entre 1 et 6, avec la formule du cours
  9. Afficher le texte Lecteur tiré au sort : puis gagnant

🔍 Comment vérifier

Une fois les seize étapes faites, la console doit afficher sept lignes : 

Emprunts : 4
string number number
Moyenne brute : 249.66666666666666
Moyenne arrondie : 250
Le plus long : 312
Prix TTC : 28.80 €
Lecteur tiré au sort : 3        ← un nombre entre 1 et 6
Ce que vous vérifiez Ce que vous devez constater
Le compteur Emprunts : 4 — et non 3 ni 01
Les types Exactement string number number, dans cet ordre
L'arrondi La moyenne brute est décimale, l'arrondie vaut 250 : l'arrondi change la valeur
Le prix 28.80 € avec deux décimales — et non 28.799999999999997
Le tirage Rechargez dix fois : le nombre change, et reste toujours entre 1 et 6
Aucun oubli Ctrl+F sur « TODO » dans script.js : aucun résultat

🧪 Manip — à quoi sert vraiment const

  1. Terminez les seize étapes et rechargez.
  2. Dans la console, tapez PRIX_ABONNEMENT = 30 puis Entrée.
  3. Tapez maintenant nombreEmprunts = 30 puis Entrée.

Le premier déclenche TypeError: Assignment to constant variable. Le second passe sans rien dire. C'est toute la différence : le mot-clé que vous choisissez décide si le navigateur vous protège ou vous laisse faire.

🏁 Comment savoir que j'ai fini

  • Les sept lignes s'affichent, sans erreur rouge
  • Vous savez dire, pour chaque variable, pourquoi elle est en const ou en let
  • Vous savez que .toFixed() sert à afficher, pas à calculer
  • Aucun TODO ne subsiste dans script.js
