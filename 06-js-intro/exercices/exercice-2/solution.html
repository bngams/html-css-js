Les trois choses à retenir

1 · prompt() renvoie toujours du texte

C'est le cœur de l'exercice. Le visiteur tape 25, vous croyez recevoir le nombre 25 : vous recevez la chaîne "25". 

"25" + 1          → "251"     le + assemble deux textes
Number("25") + 1  → 26        le + additionne deux nombres

Et rien ne vous prévient : aucune erreur rouge, juste un résultat absurde. Exactement comme le 3,5 + 1 de l'exercice 1, c'est un piège silencieux — le plus dangereux.

Number() est la solution : il transforme un texte en nombre. Si le texte n'est pas un nombre — Number("abc") — vous obtenez NaN, pour Not a Number. Vous le croiserez, et c'est souvent le signe qu'une conversion a été oubliée quelque part.

2 · Trois valeurs, trois types

Le récapitulatif de l'étape 10 affiche trois valeurs de natures différentes, et la console les colore différemment :

Valeur Vient de Type
prenom prompt() string — du texte
age Number(...) number — un nombre
newsletter confirm() boolean — vrai ou faux

L'instruction typeof permet de le vérifier à tout moment : typeof age répond "number". C'est le sujet de l'exercice 3.

3 · alert() parle au visiteur, console.log() vous parle à vous

Les deux affichent un message, mais pas au même destinataire, et pas avec les mêmes conséquences :

alert() console.log()
Destinataire le visiteur vous
Bloque la page oui, jusqu'au clic non
Dans un site livré rare, et jamais pour déboguer à retirer avant la mise en ligne

Un réflexe à prendre dès aujourd'hui : quand votre code ne fait pas ce que vous attendez, n'essayez pas de deviner. Placez un console.log() juste avant la ligne suspecte, et regardez ce qu'elle contient vraiment. C'est la méthode la plus rentable du métier.
