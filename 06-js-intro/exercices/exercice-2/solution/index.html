Médiathèque des Trois Rivières

Ceci est le corrigé en fonctionnement. Les boîtes de dialogue s'ouvrent les unes après les autres dès le chargement.

Ouvrez la console (F12) avant de recharger : la moitié du résultat s'y affiche.

Ce que vous devez observer

  1. Dans la console : Le script est chargé
  2. Une alerte de bienvenue
  3. Une question : votre prénom
  4. Une alerte qui vous salue par ce prénom
  5. Une question : votre âge
  6. Dans la console, le calcul faux puis le calcul juste
  7. Une question à deux boutons, puis le récapitulatif dans la console
