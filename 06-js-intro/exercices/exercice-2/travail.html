Médiathèque des Trois Rivières

Cette page est volontairement presque vide. Tout ce qui va se passer vient du fichier script.js que vous écrivez.

Rechargez la page après chaque enregistrement : les boîtes de dialogue s'ouvriront les unes après les autres.

Avant de commencer

  1. Ouvrez la console : F12 → onglet Console
  2. Gardez-la ouverte pendant tout l'exercice
  3. Ouvrez script.js dans VSCode
  4. Enregistrez avec Ctrl+S, puis rechargez avec F5

Une partie de votre travail s'affichera dans les boîtes, et une autre dans la console. Il faut donc regarder les deux.
