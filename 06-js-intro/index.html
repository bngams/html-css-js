Découvrir JavaScript

Vos pages savent se montrer. Elles vont apprendre à agir. On commence par le plus direct : parler au navigateur, et l'écouter répondre.

  • Exercice 1 La console du navigateur 🎯 votre premier code, sans aucun fichier
  • Exercice 2 Parler à l'utilisateur 🎯 alert · confirm · prompt · console.log
  • Exercice 3 Des variables et des calculs 🎯 let · const · types · Math
  • Exercice 4 Du JavaScript dans une page 🎯 la balise script · où la placer · et pourquoi

⚠️ Ce projet change de forme. L'exercice 1 se fait entièrement dans la console du navigateur — aucun fichier à modifier. Les suivants reviennent progressivement au code écrit.
