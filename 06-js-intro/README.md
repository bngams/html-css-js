# Projet 6 — Découvrir JavaScript

**Jour 2 · matin · 4 exercices · guidage : très guidé**

Premier contact avec le troisième langage du web. Après HTML (ce que les choses
**sont**) et CSS (à quoi elles **ressemblent**), JavaScript décrit ce qu'elles
**font**.

---

## ⚠️ Ce projet change de forme — encore

| Exercice | Où vous travaillez | Fichier à modifier |
|---|---|---|
| **1** | 🖥️ **dans la console du navigateur** | **aucun** |
| **2** | la console, puis un fichier | `script.js` |
| **3** | un fichier | `script.js` |
| **4** | deux fichiers | `travail.html` **et** `script.js` |

L'exercice 1 ne vous demande **rien à écrire dans un fichier** : vous tapez
directement dans la console du navigateur et vous voyez le résultat aussitôt.
C'est la façon la plus rapide de découvrir un langage — aucune installation,
aucun enregistrement, aucun rechargement.

Les exercices suivants reviennent au code écrit, en suivant le fil
« **comment charge-t-on du JavaScript ?** » :

1. la console (exercice 1)
2. une balise `<script>` dans la page (exercices 2 et 4)
3. un fichier `.js` séparé (exercices 3 et 4)

---

## 🖥️ Ouvrir la console — à savoir avant de commencer

| Navigateur | Raccourci |
|---|---|
| **Chrome / Edge** | `F12`, puis onglet **Console** |
| **Firefox** | `F12`, puis onglet **Console** |
| **Safari** | `Cmd+Alt+C` (à activer d'abord dans *Réglages → Avancés → Menu Développement*) |

Sur tous : **clic droit sur la page → Inspecter**, puis l'onglet **Console**.

> 💡 C'est le même panneau que vous utilisez depuis le projet 3 pour inspecter
> le CSS — vous y ouvrez simplement un autre onglet.

---

## 📋 Les exercices

| # | Titre | Ce que vous allez apprendre |
|---|---|---|
| **1** | La console du navigateur | Taper du code et voir le résultat immédiatement |
| **2** | Parler à l'utilisateur | `alert`, `confirm`, `prompt`, et `console.log` |
| **3** | Des variables et des calculs | `let`, `const`, les types, l'objet `Math` |
| **4** | Du JavaScript dans une page | La balise `<script>`, où la placer, et pourquoi ça compte |

## ✅ Vous avez terminé quand…

- [ ] Vous savez ouvrir la console de votre navigateur sans hésiter
- [ ] Vous savez y taper une instruction et lire ce qu'elle renvoie
- [ ] Vous savez faire afficher un message à l'utilisateur, et lui poser une question
- [ ] Vous savez créer une variable et vous en servir dans un calcul
- [ ] Vous savez charger un fichier `.js` depuis une page HTML
