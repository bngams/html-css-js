🎯 Objectif — Construire le formulaire d'inscription à une sortie du club : identité, choix, préférences et message.

Niveau : débutant. Prérequis : le projet 1 (notamment l'attribut id) et les exercices 1 et 2 de ce projet.

📄 Le fichier à modifier

Un seul fichier : exercices/exercice-3/travail.html

Le premier champ vous est donné en entier comme modèle. Les suivants sont à écrire sur le même moule.

✅ Critères de réussite

Le formulaire doit contenir, dans cet ordre :

  1. Un champ Nom — texte, obligatoire (fourni en modèle)
  2. Un champ E-mail — du type qui fait vérifier la présence d'un @ par le navigateur, obligatoire
  3. Un champ Date de naissance — du type qui affiche un sélecteur de date
  4. Une liste déroulante « Sortie souhaitée » avec les quatre sorties du club : Pic du Midi, Boucle des trois lacs, Crêtes de Bassiès, Cascade d'Ars
  5. Un groupe de deux boutons radio « Demi-journée » / « Journée entière », réunis dans un <fieldset> avec une <legend>
  6. Une case à cocher « Je souhaite recevoir la newsletter »
  7. Une zone de texte « Message » de 5 lignes, vide au départ
  8. Un bouton d'envoi portant le texte « M'inscrire »
  9. Chaque champ a son étiquette, reliée par la paire for / id

🔍 Comment vérifier

Ce que vous vérifiez Ce que vous devez voir
Le lien étiquette ↔ champ Cliquez sur le texte de chaque étiquette : le curseur doit sauter dans le champ correspondant (ou cocher la case). C'est le test le plus fiable — s'il échoue, le for et l'id ne correspondent pas
Les boutons radio Cocher l'un décoche l'autre. Si les deux restent cochables ensemble, c'est que leurs name diffèrent
La date Un clic ouvre un petit calendrier fourni par le navigateur
La zone de texte Elle est vide. Si du texte ou des espaces y apparaissent, c'est qu'il y a du contenu entre les deux balises
Les champs obligatoires Cliquez « M'inscrire » sans rien remplir : le navigateur affiche lui-même un message et bloque l'envoi

Le formulaire n'enverra rien nulle part, et c'est voulu : traiter les données demande un serveur ou du JavaScript. Selon votre navigateur, la page se rechargera simplement. Vous verrez l'envoi au jour 3.

🧪 Manip — casser volontairement le lien étiquette / champ

  1. Dans le champ Nom (celui fourni), modifiez le for du label : remplacez nom par nomm.
  2. Enregistrez, rechargez, puis cliquez sur le mot « Nom ».

Plus rien ne se passe : le curseur ne saute plus dans le champ. C'est la seule manifestation visible de l'erreur — aucun message, aucun avertissement. Voilà pourquoi une coquille entre for et id est si facile à laisser passer.

Remettez nom avant de continuer.

🏁 Comment savoir que j'ai fini

  • Ctrl+F sur <!- : aucun commentaire de consigne ne subsiste
  • Chaque étiquette réagit au clic — testez-les toutes, une par une
  • Le validateur du W3C ne signale aucune erreur. Il repère notamment un for qui ne correspond à aucun id

⏱️ Durée indicative

35 à 45 minutes. C'est l'exercice le plus long du projet, mais aussi le plus répétitif : une fois le modèle du premier champ compris, les suivants s'enchaînent.
