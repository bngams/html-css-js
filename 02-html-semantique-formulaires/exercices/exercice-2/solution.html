Le point qui se discute : <th> ou <td> pour le nom ?

La tentation est d'écrire les quatre noms de sorties en <td> : après tout, ce sont bien des données. Mais posez la question autrement : si on vous lit « 14 km » sans rien d'autre, que manque-t-il ? Il manque de quelle sortie il s'agit.

Le nom de la sortie identifie sa ligne — c'est la définition d'un en-tête. D'où <th scope="row">.

Le test : une cellule est un en-tête si elle sert à désigner les autres cellules plutôt qu'à porter une information propre. La colonne de gauche d'un tableau en est très souvent un.

Les erreurs fréquentes

Symptôme Cause probable
Une colonne est décalée sur une ligne Cette ligne n'a pas le même nombre de cellules que les autres — comptez-en trois par <tr>
Le titre s'affiche à l'intérieur du tableau, dans une cellule Le <caption> a été placé après une ligne. Sa place est juste après <table>
Rien n'est en gras Toutes les cellules sont en <td> : aucune n'a été déclarée comme en-tête
Le tableau n'a aucune bordure C'est normal. Le HTML décrit la structure, le CSS l'apparence — projet 3
Le validateur signale « Element tbody not allowed here » Le <tbody> est en dehors du <table>, ou le <thead> n'a pas été fermé

Le réflexe qui fait gagner du temps : écrivez une ligne complète et correcte, vérifiez-la dans le navigateur, puis copiez-collez-la pour les suivantes en ne changeant que les valeurs. Un tableau est répétitif — autant ne pas répéter les erreurs.
