# Projet 8 — Répéter et ranger

**Jour 2 · fin d'après-midi · 4 exercices · guidage : semi-guidé**

Au projet 7, votre code savait **décider**. Il va maintenant apprendre à
**répéter** (les boucles) et à **ranger** plusieurs valeurs ensemble (les tableaux,
les objets, les classes).

---

## 🎯 La promesse tenue

Le jeu de devinette du projet 7 n'accordait **qu'un seul essai** — faute de boucle.
À la fin de ce projet, vous saurez le faire redemander.

---

## 📋 Les exercices

| # | Titre | Ce que vous allez apprendre |
|---|---|---|
| **1** | Des listes et des boucles | Les tableaux, `.length`, `for`, `for…of` |
| **2** | Boucler jusqu'à trouver | `while`, et le jeu de devinette qui redemande |
| **3** | Décrire une chose : les objets | `{ clé: valeur }`, la notation JSON |
| **4** | Des moules à objets : les classes | `class`, `constructor`, `this`, les méthodes |

---

## ⚠️ Ce qui change de forme

Le guidage se desserre : les commentaires des squelettes sont **plus courts** qu'au
projet 7, et certaines étapes ne détaillent plus chaque geste. C'est voulu — vous
avez maintenant de quoi chercher par vous-même, et le cours reste à portée d'onglet.

Le fichier reste `app.js`, chargé par `<script src="app.js"></script>`.

---

## 📦 Et pour finir : à quoi ressemble un vrai projet

En fin de projet, une page de **démonstration** (sans exercice) montre comment un
code qui grossit se découpe en plusieurs fichiers, avec
`<script type="module">` et `import` / `export`.

👉 **[Ouvrir la démonstration](modules/)** — à lire après l'exercice 4.

**C'est une lecture, pas un TP** — une dizaine de minutes. L'objectif est que vous
*reconnaissiez* ces lignes quand vous ouvrirez un projet existant, pas que vous
sachiez les écrire aujourd'hui.

C'est la dernière étape du fil commencé au projet 6 :

| Projet | Comment le JS est chargé |
|---|---|
| **P6** | la console, puis `<script>` dans la page |
| **P7** | un fichier `app.js` séparé |
| **P8** | *(montré)* plusieurs fichiers avec `import` / `export` |

---

## ✅ Vous avez terminé quand…

- [ ] Vous savez parcourir un tableau avec `for` et avec `for…of`
- [ ] Vous savez pourquoi une boucle s'arrête à `i < length` et non `i <= length`
- [ ] Vous savez répéter une action jusqu'à ce qu'une condition soit remplie
- [ ] Vous savez décrire une chose avec un objet, et lire ses propriétés
- [ ] Vous savez écrire une classe avec un constructeur et une méthode
- [ ] Vous reconnaissez `import` / `export` quand vous les croisez
