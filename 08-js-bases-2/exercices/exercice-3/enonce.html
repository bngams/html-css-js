🎯 Objectif — Décrire une chose avec un objet, parcourir ses propriétés, et découvrir JSON, la notation de toutes les données du web.

Prérequis : les exercices 1 et 2 (tableaux, for…of, boucles) et le projet 7 (const, typeof).

Un seul fichier : exercices/exercice-3/app.js

Le catalogue — un tableau de trois livres — vous est fourni. La fiche du premier objet, c'est vous qui l'écrivez.

✅ Le travail — 15 étapes

Elles sont courtes : la plupart tiennent en une ligne. C'est le nombre de notions qui monte, pas la difficulté de chacune.

Partie 1 — créer et lire un objet

  1. Créer un objet livre avec trois clés : titre (La Horde du Contrevent), auteur (Damasio), pages (712)
  2. Afficher Titre : puis le titre, avec l'écriture à point
  3. Afficher Auteur : puis l'auteur, avec l'écriture à crochets
  4. Afficher Éditeur : puis livre.editeur — une clé qui n'existe pas encore

Partie 2 — modifier l'objet

  1. Ajouter à livre une clé editeur valant La Volte
  2. Afficher Après ajout : puis livre.editeur

Partie 3 — parcourir

  1. Avec for…in, afficher une ligne par propriété : ·, la clé, =, la valeur — en lisant la valeur avec des crochets

Partie 4 — un tableau d'objets

  1. Afficher 1er du catalogue : puis le titre du premier livre
  2. Avec for…of, afficher une ligne par livre : → puis son titre
  3. Calculer dans totalPages la somme des pages, avec une boucle — pas à la main
  4. Afficher Total des pages : puis totalPages

Partie 5 — JSON

  1. Ranger dans livreTexte l'objet transformé en texte JSON
  2. Afficher, en une instruction : JSON :, livreTexte, · type :, puis le type de livreTexte
  3. Ranger dans livreRetrouve ce texte redevenu objet
  4. Afficher Retrouvé :, le titre de livreRetrouve, · type :, puis son type

🧪 Manip — le piège à deux étages

Dans la console de la page de travail, tapez ces deux lignes :

  1. livre.horaires → undefined, sans erreur
  2. livre.horaires.lundi → TypeError: Cannot read properties of undefined

Chercher une clé absente est permis ; aller chercher dedans ne l'est pas. C'est le mécanisme exact du projet 7, quand querySelector ne trouvait rien. Quand ce message apparaît, remontez d'un cran : c'est le niveau au-dessus qui manque.

🧪 Manip — la preuve que le JSON est du texte

Une fois l'étape 12 faite, tapez dans la console :

  1. livreTexte.titre → undefined
  2. livreRetrouve.titre → le vrai titre

Le premier contient les caractères « titre », mais c'est une chaîne : elle n'a pas de propriété de ce nom. Le second est redevenu un objet. Voilà toute la différence, en deux lignes.

🏁 Comment savoir que j'ai fini

  • Les quinze lignes s'affichent, dans l'ordre, sans erreur rouge
  • Vous savez quand utiliser les crochets plutôt que le point
  • Vous savez que JSON.stringify rend du texte, pas un objet
  • Aucun TODO ne subsiste dans app.js
