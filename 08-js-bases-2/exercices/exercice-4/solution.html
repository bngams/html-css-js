Le fichier complet

Afficher app.js en entier 
class Rectangle {

  constructor(largeur, hauteur) {
    this.largeur = largeur;
    this.hauteur = hauteur;
  }

  calculAire() {
    return this.largeur * this.hauteur;
  }

  calculPerimetre() {
    return 2 * (this.largeur + this.hauteur);
  }

  decrire() {
    return "Rectangle " + this.largeur + "×" + this.hauteur +
           ", aire " + this.calculAire();
  }
}

const premier = new Rectangle(10, 5);

console.log("Premier :", premier.largeur, "×", premier.hauteur);
console.log("Aire :", premier.calculAire());
console.log("Périmètre :", premier.calculPerimetre());
console.log("Description :", premier.decrire());

const formes = [
  new Rectangle(2, 3),
  new Rectangle(4, 5),
  new Rectangle(6, 7)
];

for (const forme of formes) {
  console.log("·", forme.decrire());
}

let totalAires = 0;

for (const forme of formes) {
  totalAires = totalAires + forme.calculAire();
}

console.log("Total des aires :", totalAires);

console.log("En JSON :", JSON.stringify(premier));

Les quatre choses à retenir

1 · this. fait le lien avec l'objet courant

L'erreur numéro un sur ce chapitre. Dans une méthode, largeur seul ne désigne rien : 

return largeur * this.hauteur;
→ ReferenceError: largeur is not defined

JavaScript cherche une variable de ce nom — il n'en existe pas. this.largeur dit « la largeur de cet objet-ci ».

La règle vaut aussi pour appeler une méthode depuis une autre : this.calculAire() dans decrire().

2 · Un moule, trois objets, trois résultats

FabricationcalculAire()
new Rectangle(2, 3)6
new Rectangle(4, 5)20
new Rectangle(6, 7)42

La méthode est écrite une seule fois, dans la classe. Chaque objet l'exécute avec ses valeurs. C'est le même gain qu'une fonction au projet 7 — appliqué à des objets entiers.

Les objets sont indépendants : modifier l'un ne touche ni les autres, ni le moule. C'est pour cela qu'on peut en fabriquer cent sans qu'ils se gênent.

3 · Oublier new : une erreur qui se voit

Rectangle(10, 5)
→ TypeError: Class constructor Rectangle cannot be invoked without 'new'

Le message dit exactement quoi corriger. Après tous les pièges silencieux de ce cours — le undefined d'un return manquant, le NaN d'une conversion oubliée, la ligne en trop d'un <= — celui-là est une faveur.

4 · JSON ne transporte pas le comportement

JSON.stringify(premier) donne {"largeur":10,"hauteur":5}. Les données sont là ; les méthodes ont disparu. 

const copie = JSON.parse(JSON.stringify(premier));

copie.largeur              → 10        ✅
copie instanceof Rectangle → false     ⚠️
copie.calculAire()         → TypeError: copie.calculAire is not a function

L'objet revenu ressemble à un rectangle, mais il a perdu son moule. C'est la suite exacte de l'exercice 3, où une fonction disparaissait du JSON sans avertissement.

Au passage : instanceof répond à la question « cet objet sort-il de ce moule ? ». Ce n'est pas au programme d'aujourd'hui — aucune étape ne le demande — mais c'est le mot exact pour ce que vous venez de constater.

Les erreurs fréquentes

SymptômeCause
ReferenceError: largeur is not defined Un this. manque dans une méthode ou dans le constructor
TypeError: Class constructor Rectangle cannot be invoked without 'new' Le mot-clé new manque à la fabrication
Aire : undefined La méthode n'a pas de return — le piège du projet 7, exercice 2
SyntaxError: Unexpected token '{' Une méthode est écrite hors des accolades de la classe. Tout le fichier s'arrête : même les lignes qui marchaient ne s'affichent plus. Remontez la méthode à l'intérieur de class Rectangle { … }
TypeError: premier.calculAire is not a function La méthode n'a pas été écrite, ou son nom est mal orthographié (majuscules comprises)
SyntaxError dans la classe Une virgule entre deux méthodes : contrairement aux objets littéraux, les méthodes d'une classe ne se séparent pas par des virgules
Total des aires : 0 L'addition est hors de la boucle, ou vous additionnez forme au lieu de forme.calculAire()
