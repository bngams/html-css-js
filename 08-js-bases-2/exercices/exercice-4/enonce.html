🎯 Objectif — Fabriquer plusieurs objets sur un même moule, et leur donner des savoir-faire.

Prérequis : l'exercice 3 (objets, tableau d'objets, JSON) et le projet 7 (fonctions, return).

Un seul fichier : exercices/exercice-4/app.js

🎓 Dernier exercice du projet 8 — et du jour 2.

⚠️ Une particularité : quatre étapes enrichissent la MÊME classe.

Les étapes 1, 4, 6 et 8 ajoutent chacune un morceau à class Rectangle. Écrivez-les à l'intérieur de ses accolades, pas à la suite du fichier.

✅ Le travail — 14 étapes

Partie 1 — le moule

  1. Écrire une classe Rectangle dont le constructor reçoit largeur et hauteur, et les range dans l'objet — avec this.
  2. Ranger dans premier un Rectangle de 10 sur 5, fabriqué avec le mot-clé du cours §3
  3. Afficher, en une instruction : Premier :, sa largeur, ×, sa hauteur

Partie 2 — les savoir-faire

  1. Ajouter à la classe une méthode calculAire() qui renvoie largeur × hauteur
  2. Afficher Aire : puis le résultat — vous devez obtenir 50
  3. Ajouter calculPerimetre() qui renvoie 2 × (largeur + hauteur)
  4. Afficher Périmètre : puis le résultat — vous devez obtenir 30
  5. Ajouter decrire() qui renvoie un texte de la forme Rectangle 10×5, aire 50, en appelant calculAire() depuis l'intérieur
  6. Afficher Description : puis le résultat

this. n'est pas optionnel. Dans une méthode, écrire largeur seul déclenche ReferenceError: largeur is not defined : JavaScript cherche une variable, pas la propriété de l'objet.

Même chose pour appeler une méthode depuis une autre : this.calculAire().

Partie 3 — plusieurs objets sur le même moule

  1. Ranger dans formes un tableau de trois Rectangle : 2×3, 4×5, 6×7
  2. Avec for…of, afficher une ligne par forme : · puis sa description
  3. Calculer dans totalAires la somme des aires, avec une boucle
  4. Afficher Total des aires : puis totalAires

Partie 4 — ce que JSON ne transporte pas

  1. Afficher En JSON : puis premier transformé en texte JSON — et regarder ce qui manque

🔍 Comment vérifier

Décompte : sept console.log, neuf lignes affichées. L'étape 11 est une boucle sur trois formes.

La console doit afficher exactement ceci :

Premier : 10 × 5
Aire : 50
Périmètre : 30
Description : Rectangle 10×5, aire 50
· Rectangle 2×3, aire 6
· Rectangle 4×5, aire 20
· Rectangle 6×7, aire 42
Total des aires : 68
En JSON : {"largeur":10,"hauteur":5}
Ce que vous vérifiez Ce que vous devez constater
Le moule fonctionne Aire : 50 et Périmètre : 30
Une méthode appelle l'autre La description contient l'aire calculée, pas un nombre écrit à la main
Trois objets indépendants Trois aires différentes : 6, 20 et 42 — le même moule, trois résultats
Le total 68, obtenu par une boucle
Ce que JSON perd {"largeur":10,"hauteur":5} — les données sont là, les méthodes ont disparu
Aucun oubli Ctrl+F sur « TODO » dans app.js : aucun résultat

🧪 Manip — un objet qui a perdu son moule

Dans la console de la page de travail, tapez ces trois lignes :

  1. const copie = JSON.parse(JSON.stringify(premier));
  2. copie.largeur → 10, les données sont là
  3. copie.calculAire() → TypeError: copie.calculAire is not a function

L'objet revenu de JSON ressemble à un rectangle, mais ce n'en est plus un. C'est la suite directe de l'exercice 3 : JSON transporte des données, jamais du comportement.

🏁 Comment savoir que j'ai fini

  • Les neuf lignes s'affichent, sans erreur rouge
  • Vous savez pourquoi this. est nécessaire dans une méthode
  • Vous savez ce que new fait — et ce qui se passe si on l'oublie
  • Aucun TODO ne subsiste dans app.js
