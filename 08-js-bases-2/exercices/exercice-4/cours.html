Projet 8 · Exercice 4

Des moules à objets : les classes

  • 📖 Cours
  • 📋 Énoncé
  • ✍️ À vous de jouer
  • ✅ Solution

Ce que vous allez apprendre ici : fabriquer plusieurs objets sur le même moule, et leur donner des savoir-faire — pas seulement des données.

1 · Le problème : cent fiches, cent copies

À l'exercice 3, vous écriviez chaque objet à la main. Pour trois livres, cela va. Pour cent rectangles, on recopie cent fois la même structure — et si l'on oublie une clé quelque part, rien ne le signale. 

const r1 = { largeur: 10, hauteur: 5 };
const r2 = { largeur: 2, hauteur: 3 };
const r3 = { largeur: 7 };              ← hauteur oubliée, aucune alerte

Une classe est un moule : on la décrit une fois, et l'on fabrique autant d'objets qu'on veut, tous bâtis pareil.

2 · Écrire une classe

class Rectangle {
  constructor(largeur, hauteur) {
    this.largeur = largeur;
    this.hauteur = hauteur;
  }
}
Le morceauSon rôle
class« je décris un moule »
Rectangleson nom — majuscule initiale, par convention
constructorla recette de fabrication, appelée automatiquement
this« l'objet qu'on est en train de fabriquer »

La majuscule n'est pas décorative. Tout le métier écrit les noms de classes avec une majuscule (Rectangle, Date) et les variables en minuscule (rectangle). C'est ce qui permet de reconnaître un moule d'un coup d'œil.

3 · Fabriquer : le mot-clé new

const r = new Rectangle(10, 5);

r.largeur     → 10
r.hauteur     → 5

new crée un objet vide, exécute le constructor dessus — c'est lui que this désigne — et vous le rend.

Oublier new ne passe pas inaperçu, et c'est une bonne nouvelle : 

Rectangle(10, 5)
→ TypeError: Class constructor Rectangle cannot be invoked without 'new'

Le message dit exactement quoi faire. Contrairement à la plupart des pièges de ce cours, celui-là se voit.

4 · Donner un savoir-faire : les méthodes

Jusqu'ici vos objets ne contenaient que des données. Une classe leur ajoute des actions : 

class Rectangle {
  constructor(largeur, hauteur) {
    this.largeur = largeur;
    this.hauteur = hauteur;
  }

  calculAire() {
    return this.largeur * this.hauteur;
  }
}

const r = new Rectangle(10, 5);
r.calculAire()     → 50

Une méthode est une fonction rangée dans un objet. Vous savez déjà tout faire : des paramètres, un return — comme au projet 7. Deux différences d'écriture seulement : pas de function devant, et pas de virgule entre les méthodes.

5 · ⚠️ this n'est pas optionnel

L'erreur la plus fréquente des débutants sur ce chapitre. Dans une méthode, les données de l'objet ne sont pas accessibles par leur nom seul : 

calculAire() {
  return largeur * hauteur;     ← ✋ sans this
}
→ ReferenceError: largeur is not defined

JavaScript cherche une variable nommée largeur, pas la propriété de l'objet. Il faut écrire this.largeur — « la largeur de cet objet-ci ».

La même règle vaut dans le constructor : sans this., la valeur reçue n'est rangée nulle part.

Une méthode peut en appeler une autre

decrire() {
  return "Aire : " + this.calculAire();
}

Là encore, this. est nécessaire : c'est ainsi qu'on désigne « la méthode de cet objet ».

6 · Chaque objet vit sa vie

const a = new Rectangle(2, 3);
const b = new Rectangle(10, 10);

a.largeur = 99;

a.largeur     → 99
b.largeur     → 10     ← intact

Le moule sert à fabriquer ; une fois sortis, les objets sont indépendants. Modifier l'un ne touche pas les autres, ni la classe elle-même.

7 · Un tableau d'objets… fabriqués

Vous savez déjà parcourir un tableau d'objets — c'était l'exercice 3. Rien ne change, sinon qu'on peut maintenant appeler leurs méthodes : 

const formes = [
  new Rectangle(2, 3),
  new Rectangle(4, 5)
];

for (const f of formes) {
  console.log(f.calculAire());
}

8 · Classe ou objet littéral ?

Objet littéral { … }Classe
Pour une chose, décrite une fois plusieurs choses du même genre
Contient des données des données et des savoir-faire
Exemple la fiche de votre médiathèque le moule d'un livre, d'un rectangle

Et JSON dans tout ça ? Souvenez-vous de l'exercice 3 : les fonctions ne survivent pas à JSON.stringify. C'est vrai aussi des méthodes : 

JSON.stringify(r)      → {"largeur":10,"hauteur":5}      ← que les données

const copie = JSON.parse(JSON.stringify(r));
copie.calculAire()     → TypeError: copie.calculAire is not a function

L'objet revenu de JSON ressemble à un rectangle, mais ce n'en est plus un : il a perdu son moule. Encore une fois, l'apparence n'est pas le type.
