Le nombre mystère — deuxième chance

Ceci est le corrigé en fonctionnement. Ouvrez la console (F12) avant de recharger : le nombre secret y est affiché.

Le jeu vous redemandera tant que vous n'aurez pas trouvé — c'est tout l'objet de cet exercice.

Ce qui se passe au chargement

  1. Le compte à rebours s'affiche dans la console, puis Décollage !
  2. Les démonstrations de break et continue suivent
  3. Le secret est annoncé [triche]
  4. La partie commence : une boîte, autant de fois qu'il le faudra

Essayez d'annuler en cours de partie : le jeu s'arrête proprement et affiche Partie abandonnée.

C'est le test saisie === null qui le permet. Sans lui, annuler relancerait la question indéfiniment — vous ne pourriez plus quitter la page.
