const fruits = ["Pomme", "Banane", "Cerise", "Mangue", "Poire"];

console.log("Nombre de fruits :", fruits.length);
console.log("3e fruit :", fruits[2]);
console.log("Dernier :", fruits[fruits.length - 1]);
console.log("Case 5 :", fruits[5]);

for (let i = 0; i < fruits.length; i++) {
  console.log("→", i, fruits[i]);
}

for (const fruit of fruits) {
  console.log("·", fruit);
}

fruits.push("Kiwi");

console.log("Après ajout :", fruits.length);

const listeTexte = fruits.join(" - ");

console.log("Liste :", listeTexte);

Les quatre choses à retenir

1 · Huit instructions, seize lignes

C'est la découverte de cet exercice. Vous avez écrit huit console.log, la console en affiche seize — parce que deux d'entre eux sont dans une boucle et s'exécutent cinq fois chacun.

Une boucle, c'est une instruction écrite une fois et exécutée autant de fois qu'il le faut. Avec cinquante fruits, votre code n'aurait pas une ligne de plus.

2 · Zéro, et length - 1

ExpressionValeur
fruits[0]"Pomme" — la première case
fruits[2]"Cerise" — le troisième fruit
fruits.length5
fruits[fruits.length - 1]"Poire" — la dernière
fruits[5]undefined — aucune erreur

Écrire fruits[4] à l'étape 3 aurait « marché »… jusqu'à l'étape 7. Après le push, la dernière case devient la 5 — length - 1 reste juste, un nombre en dur devient faux.

3 · Le piège du <=

Avec i <= fruits.length, la boucle fait six tours au lieu de cinq, et la dernière ligne affiche : 

→ 5 undefined

Aucune erreur rouge. JavaScript répond « rien » pour une case absente et continue. C'est le genre de défaut qui traverse une page entière sans être vu — toujours i < length.

for…of n'a pas ce problème : sans index, pas de borne à rater. C'est une raison de le préférer quand le numéro ne sert à rien.

4 · const protège la boîte, pas son contenu

fruits.push("Kiwi");         ✅ autorisé
fruits = ["Autre chose"];    ✋ TypeError: Assignment to constant variable.

const interdit de remplacer le tableau, pas d'y ajouter des cases. C'est pour cela qu'on déclare presque toujours un tableau avec const, même quand on compte le modifier.

Les erreurs fréquentes

SymptômeCause
Une ligne undefined à la fin d'une liste i <= length au lieu de i < length : un tour de trop
Le « 3e fruit » affiche Mangue Vous avez écrit fruits[3] : les index partent de zéro
La boucle for…of affiche 0, 1, 2… Vous avez écrit for…in, qui donne les index (et en texte) — voir le cours, §6
TypeError: Assignment to constant variable. Vous avez écrit fruits = … au lieu de fruits.push(…)
La liste finale n'a pas de séparateurs join() sans argument colle avec des virgules — il faut join(" - ")
SyntaxError: Unexpected token ')' Il manque un point-virgule : un for a besoin de trois parties, séparées par deux points-virgules
La boucle ne s'arrête jamais, l'onglet se fige Les trois parties sont là, mais la troisième est vide (i < length;) ou fait reculer le compteur (i--) : il faut i++. Fermez l'onglet (Ctrl+W) — pas le navigateur entier — corrigez, rouvrez
