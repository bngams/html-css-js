Le modèle de boîte

  • 📖 Cours
  • 📋 Énoncé
  • ✍️ À vous de jouer
  • ✅ Solution

Ce que vous allez apprendre ici : maîtriser les espacements. C'est la notion qui explique pourquoi une page « ne se place pas comme on veut ».

1 · Tout élément est une boîte

C'est le principe à intégrer une fois pour toutes : chaque élément HTML occupe une boîte rectangulaire. Un titre, un paragraphe, une image, un lien — tous. Même quand ça ne se voit pas.

Cette boîte se compose de quatre couches, de l'intérieur vers l'extérieur :

Couche Rôle
le contenu Le texte ou l'image elle-même
padding L'espace intérieur, entre le contenu et la bordure
border Le trait qui entoure
margin L'espace extérieur, qui éloigne des éléments voisins

L'image qui aide : pensez à un cadre photo accroché au mur. La photo est le contenu. Le passe-partout blanc autour, c'est le padding. Le cadre en bois, c'est la border. Et l'espace qui le sépare des autres cadres, c'est la margin.

2 · padding ou margin ?

La confusion entre les deux est le passage obligé. Un seul test permet de trancher :

Le fond de l'élément s'étend-il dans cet espace ?

  • Oui → c'est du padding. Il est dedans.
  • Non → c'est de la margin. Elle est dehors.

Concrètement : si vous donnez un fond bleu à un bouton et que vous voulez que le bleu déborde autour du texte, c'est du padding. Si vous voulez éloigner ce bouton du suivant, c'est de la margin.

3 · Les écritures

Chaque propriété accepte de une à quatre valeurs :

padding: 20px;                  /* les 4 côtés */
padding: 10px 20px;             /* haut/bas, puis gauche/droite */
padding: 10px 20px 30px 40px;   /* haut, droite, bas, gauche */

L'ordre des quatre valeurs suit les aiguilles d'une montre, en partant du haut : haut → droite → bas → gauche. Le moyen mnémotechnique anglais est « TRouBLe » (Top, Right, Bottom, Left).

On peut aussi viser un seul côté :

margin-top: 30px;
margin-bottom: 30px;

4 · Les bordures

Une bordure se décrit en trois informations, dans cet ordre :

border: 2px solid #0b6bcb;
     /* épaisseur · style · couleur */
Style Rendu
solid Un trait plein — le plus courant
dashed Des tirets
dotted Des points

Le style est obligatoire. Écrire border: 2px #0b6bcb; sans solid n'affiche rien : par défaut, le style vaut none. C'est une panne classique, et silencieuse.

5 · Le piège de la largeur — box-sizing

Voici le comportement par défaut, qui surprend tout le monde :

.carte {
  width: 300px;
  padding: 20px;
  border: 5px solid navy;
}

Quelle largeur occupe cette carte à l'écran ? 350 pixels, pas 300 : par défaut, width ne désigne que le contenu. Les paddings et bordures s'ajoutent par-dessus.

Le calcul : 300 + 20 + 20 (paddings) + 5 + 5 (bordures) = 350.

La correction, universellement adoptée : 

* {
  box-sizing: border-box;
}

box-sizing: border-box demande que width désigne la boîte entière, bordures comprises. Votre carte fera alors exactement 300 pixels, et le contenu s'adaptera.

L'astérisque * est le sélecteur universel : il vise tous les éléments. Cette règle se place en première ligne de presque toutes les feuilles de style professionnelles.

6 · Centrer un bloc

La recette à connaître par cœur :

.conteneur {
  max-width: 800px;
  margin: 0 auto;
}

auto sur les marges gauche et droite demande au navigateur de répartir l'espace restant équitablement — ce qui centre le bloc. max-width évite qu'il s'étale sur un grand écran, tout en le laissant rétrécir sur un petit.

Deux conditions pour que ça marche : l'élément doit avoir une largeur limitée (width ou max-width), et margin: 0 auto centre horizontalement seulement. Le centrage vertical relève de Flexbox — exercice 3.

7 · Les unités

Unité Sens Quand
px Une valeur fixe Bordures, petits espacements précis
% Une part de l'élément parent Largeurs qui doivent s'adapter
rem Un multiple de la taille de base du navigateur Tailles de texte et espacements — à préférer

Pourquoi rem vaut mieux que px pour le texte : une personne malvoyante peut augmenter la taille de police par défaut de son navigateur. Les valeurs en rem suivent ce réglage ; celles en px l'ignorent. 1rem vaut 16px par défaut, donc 1.5rem = 24px.

Nous resterons en px dans cet exercice pour ne pas mélanger les difficultés, mais retenez ce point : il compte.
