Le point central : dedans ou dehors ?

Sur la classe carte, nous avons posé les deux, et c'est délibéré :

Règle Effet visible
padding: 20px Le texte ne colle plus au bord : le fond blanc s'étend autour de lui
margin-bottom: 20px Les cartes se séparent : le gris de la page apparaît entre elles

Le test qui tranche à tous les coups : le fond de l'élément s'étend-il dans cet espace ? Oui → padding. Non → margin.

Deux points que la solution pousse plus loin

Une classe de base, une classe de variante

La troisième carte porte deux classes : class="carte carte--mise-en-avant". Elle reçoit donc les deux règles, et la seconde ne redéfinit que ce qui diffère — le fond et la bordure gauche.

Tout le reste (espacements, bordure des autres côtés) vient de .carte. C'est une manière très répandue de travailler : on évite de tout réécrire pour une variante.

max-width plutôt que width

Avec width: 800px, le conteneur ferait 800px même sur un écran de téléphone — et débordrait. Avec max-width, il ne dépasse jamais 800px mais peut rétrécir librement.

C'est déjà un réflexe de responsive design, que vous approfondirez au projet 4.

Les erreurs fréquentes

Symptôme Cause probable
Aucune bordure n'apparaît Le style manque : border: 1px #d7dee8 sans solid n'affiche rien
Les cartes sont collées les unes aux autres padding a été écrit au lieu de margin-bottom : l'espace est allé à l'intérieur
Le texte colle au bord des cartes L'inverse : margin au lieu de padding
Le conteneur n'est pas centré margin: 0 auto manque, ou aucune largeur n'est limitée — les deux sont nécessaires
Une bande grise subsiste tout autour de la page margin: 0 manque sur body
Le trait bleu entoure toute la carte border a été écrit au lieu de border-left

Le réflexe qui rend la notion concrète : clic droit sur un élément → Inspecter, puis le schéma de boîte en bas du panneau Styles. Survolez chaque couche : le navigateur la surligne dans la page. Vous voyez exactement où finit le padding et où commence la marge.
