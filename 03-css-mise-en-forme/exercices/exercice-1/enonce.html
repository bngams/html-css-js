🎯 Objectif — Habiller la page d'une médiathèque : polices, couleurs, alignements. Vos premières règles CSS.

Niveau : débutant. Prérequis : les projets 1 et 2. Vous savez lire une page HTML et reconnaître ses balises, ses classes et ses id.

📄 Les fichiers — attention, ça change

À partir de ce projet, vous travaillez avec deux fichiers — et ce n'est pas le même qu'avant que vous modifiez :

Fichier Rôle
travail.html 🔒 Fourni et figé — la page à habiller. N'y touchez pas. C'est elle que vous rechargez dans le navigateur
style.css 👉 LE FICHIER QUE VOUS MODIFIEZ — vos règles

Pourquoi cette séparation ? C'est le principe fondateur du web : le HTML dit ce que les choses sont, le CSS dit à quoi elles ressemblent. Un seul fichier de style peut habiller cent pages — changez une couleur à un endroit, les cent pages suivent.

Vous rouvrirez le HTML à l'exercice 4, pour y poser vos propres points d'accroche.

🔁 La boucle de travail

  1. j'écris ma règle dans style.css
  2. j'enregistre — Ctrl+S / Cmd+S
  3. je recharge travail.html dans le navigateur — Ctrl+R / Cmd+R
  4. je regarde ce qui a changé

Le plus confortable : VSCode d'un côté avec les deux fichiers ouverts, le navigateur de l'autre sur travail.html.

✅ Critères de réussite

Dans style.css, écrivez sept règles :

  1. body — police sans empattements avec au moins un repli, taille 18px, texte #333, fond #f7f7f5
  2. h1 — couleur #14457b
  3. h2 — couleur #0b6bcb, texte centré
  4. la classe intro — texte en gras, couleur #1c2024
  5. l'id presentation — fond blanc #fff
  6. a — sans soulignement, couleur #0b6bcb
  7. footer — texte centré, taille 14px, couleur #6b7280

🔍 Comment vérifier

Ce que vous vérifiez Ce que vous devez voir
La police Le texte n'est plus en Times : les lettres n'ont plus de petits empattements aux extrémités
Les deux paragraphes intro Les deux sont en gras — celui de « Bienvenue » et celui de « Nos nouveautés ». Une classe vise tous les éléments qui la portent
Le bloc presentation Seul le bloc « Bienvenue » a un fond blanc. Celui des nouveautés garde le fond de la page : un id ne vise qu'un élément
Les liens Le soulignement a disparu et ils sont bleus
Les titres h2 « Bienvenue » et « Nos nouveautés » sont centrés

🧪 Manip — quand une règle « ne fait rien »

C'est la panne n°1 du débutant. Le navigateur sait vous dire pourquoi.

  1. Dans style.css, ajoutez volontairement une règle fautive : h3 { color: red; } — or la page ne contient aucun h3.
  2. Enregistrez, rechargez : rien ne se passe, évidemment.
  3. Clic droit sur le titre « Bienvenue » → Inspecter. Dans le panneau des styles, vous voyez toutes les règles qui s'appliquent à l'élément sélectionné — et votre h3 n'y figure pas.
  4. Cliquez maintenant sur un paragraphe intro : vous y verrez votre règle .intro listée, avec le nom du fichier et le numéro de ligne.

Retenez ce panneau : quand une règle semble ignorée, il vous dira si elle n'est pas lue du tout (sélecteur qui ne vise rien) ou si elle est écrasée par une autre — elle apparaît alors barrée.

Supprimez la règle h3 avant de continuer.

🏁 Comment savoir que j'ai fini

  • Dans style.css, Ctrl+F sur TODO : aucun résultat
  • Les cinq points du tableau de vérification sont constatés à l'écran
  • Déposez style.css sur le validateur CSS du W3C : aucune erreur. Il repère notamment les points-virgules manquants

⏱️ Durée indicative

30 à 40 minutes. Les deux premières règles demandent un effort ; les cinq suivantes s'enchaînent vite, elles suivent le même moule.
