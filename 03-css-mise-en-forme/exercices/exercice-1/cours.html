Écrire du CSS

  • 📖 Cours
  • 📋 Énoncé
  • ✍️ À vous de jouer
  • ✅ Solution

Ce que vous allez apprendre ici : écrire vos premières règles de style, choisir les éléments à habiller, et poser des couleurs et des polices.

1 · HTML dit quoi, CSS dit comment

Vos deux premiers projets décrivaient la structure : ceci est un titre, ceci un paragraphe, ceci un tableau. Le navigateur appliquait un style par défaut — du Times noir sur fond blanc — parce qu'il fallait bien afficher quelque chose.

CSS (Cascading Style Sheets) prend le relais : il décrit l'apparence. Même page, même contenu, mais vous décidez des couleurs, des tailles, des espacements et de la disposition.

2 · Les trois façons de lier du CSS

Elles existent toutes les trois, mais une seule est recommandée.

a · Dans un fichier séparé ✅ la bonne

Une balise dans le <head> de la page HTML :

<link rel="stylesheet" href="style.css">

Et tout le style vit dans style.css. C'est ce que vous ferez dans tous les exercices de ce projet.

Vous connaissez déjà cette balise : <link> est auto-fermante, comme <img> et <meta> (projet 1). Et href y désigne un chemin de fichier, exactement comme pour un lien.

Pourquoi c'est la bonne méthode : un seul fichier de style pour cent pages. Vous changez une couleur à un endroit, les cent pages suivent.

b · Dans une balise <style> ⚠️ dépannage ou contrainte technique

<head>
  <style>
    h1 { color: blue; }
  </style>
</head>

Le style ne vaut que pour cette page. Acceptable pour un essai rapide — et parfois imposé :

  • Les e-mails HTML — beaucoup de logiciels de messagerie ignorent les fichiers CSS externes ; le style doit voyager avec le message.
  • Certains CMS et outils qui ne donnent accès qu'au contenu d'une page, sans possibilité d'ajouter un fichier au serveur.
  • Une page générée d'un bloc — un export, un rapport, un fichier unique à envoyer par mail : tout doit tenir dans le même fichier.

Ce n'est donc pas une mauvaise pratique en soi : c'est une méthode dont le domaine d'emploi est étroit. Hors de ces cas, préférez le fichier séparé.

c · Dans l'attribut style ❌ à éviter

<h1 style="color: blue;">Titre</h1>

Le style ne vaut que pour cet élément. Avec vingt titres, vous écrivez vingt fois la même chose — et vous les modifiez vingt fois. C'est aussi ce qui rend une page impossible à maintenir. À connaître pour le reconnaître, pas pour l'utiliser.

3 · La syntaxe d'une règle

Une règle CSS a toujours la même forme :

h1 {
  color: blue;
  font-size: 32px;
}
Partie Nom Rôle
h1 le sélecteur Quels éléments sont visés
color la propriété Quoi changer
blue la valeur Comment

Deux signes à ne pas confondre : les deux-points : séparent la propriété de sa valeur, le point-virgule ; termine la déclaration. Oublier le ; casse la déclaration suivante, pas celle où il manque — d'où des erreurs déroutantes.

Les commentaires CSS

Ils ne s'écrivent pas comme en HTML. En CSS, c'est une barre oblique et une étoile : 

/* Ceci est un commentaire CSS */

4 · Les sélecteurs de base

Sélecteur Vise Exemple
p Tous les éléments de ce type p { … }
.intro Tous les éléments portant class="intro" .intro { … }
#menu L'élément portant id="menu" #menu { … }

Classe ou id ?

Vous connaissez déjà l'id : un nom unique dans la page (projets 1 et 2). La classe est son opposé utile : le même nom peut être posé sur autant d'éléments que vous voulez. 

<p class="intro">Premier paragraphe</p>
<p class="intro">Un autre, même style</p>

En CSS, on utilise presque toujours des classes. Styler par id ne peut toucher qu'un seul élément, ce qui est rarement ce qu'on veut. Réservez l'id aux liens internes et, plus tard, au JavaScript.

Viser plusieurs sélecteurs à la fois

h1, h2, h3 {
  color: navy;
}

La virgule signifie « et aussi ». La règle s'applique aux trois.

5 · Les couleurs

Trois écritures, du plus simple au plus précis :

Écriture Exemple Quand
Le nom red, navy, tomato Essais rapides — environ 140 noms existent
Hexadécimal #0b6bcb La plus courante en production
rgb() rgb(11, 107, 203) Quand on manipule les canaux séparément

Deux propriétés à distinguer :

p {
  color: #333;              /* la couleur du TEXTE */
  background-color: #eee;   /* la couleur du FOND */
}

6 · Les polices

body {
  font-family: Georgia, "Times New Roman", serif;
  font-size: 18px;
}

Pourquoi plusieurs noms séparés par des virgules ? C'est une liste de repli. Le navigateur essaie Georgia ; s'il ne l'a pas, Times New Roman ; sinon n'importe quelle police à empattements. Terminez toujours par une famille générique : serif, sans-serif ou monospace.

Les noms contenant un espace se mettent entre guillemets.

Trois propriétés de texte utiles dès maintenant :

Propriété Effet
font-size La taille — 18px
font-weight La graisse — bold ou normal
text-align L'alignement — left, center, right
text-decoration Le soulignement — none le retire (utile sur les liens, que le navigateur souligne par défaut)

7 · Quand deux règles se contredisent

C'est le « C » de CSS : la cascade. Deux principes suffisent ici :

p { color: blue; }
p { color: red; }     /* gagne : elle vient après */
  • À égalité, la dernière écrite gagne.
  • Le sélecteur le plus précis gagne, quel que soit l'ordre : une classe l'emporte sur une balise, un id l'emporte sur une classe.

Cela explique la panne la plus courante du débutant : « ma règle ne fait rien ». Souvent, une autre règle plus précise, écrite ailleurs, l'emporte. Vous verrez dans la manip de l'énoncé comment le navigateur vous le montre.
